# Weekly AI & Tooling Digest — 2026-W44

*Week of 2026-10-20 to 2026-10-26*

## 🔴 Critical

### [Claude Code v2.1.309](https://github.com/anthropics/claude-code/releases)
Released October 22. Adds a `/claude-api api-version` command (bumping to API version 2026-10-21) and a new OpenTelemetry event that fires whenever a permission rule, auto mode check, safety check, hook, or sandbox blocks or prompts a tool call. Earlier this month, v2.1.304 added an auto mode setup command and session usage limit warnings. Docs now consistently call "routines" "scheduled tasks."
**Why it matters:** The new OTel event gives detailed observability into every moment Claude Code is stopped mid-task — critical for debugging hooks or auto mode behavior in complex projects like Bucktee plugin workflows.

### [Claude Haiku 5.5 — Fastest Small Model, 75% Cheaper](https://www.anthropic.com/claude-haiku-5-5)
Launched October 7. Positioned as Anthropic's fastest model for high-volume subagent work at $0.10/MTok input (under 100K tokens) — roughly 75% cheaper than Haiku 4.5. First Haiku-class model with an adjustable effort setting; accepts text and image inputs. Available in Claude Code and on all major cloud platforms.
**Why it matters:** At $0.10/MTok, Haiku 5.5 is the clear choice for high-volume Claude Code subagent tasks (compaction, summarization, routing) — pairing it with Sonnet 5.5 for main coding work meaningfully reduces daily Claude Code costs.

### [Sonnet 5.5 Cache Read Price Halved to $0.10/MTok](https://docs.anthropic.com/en/docs/about-claude/pricing)
Effective October 7. Cache read price for Sonnet 5.5 dropped from $0.20 to $0.10 per million tokens, reducing costs by ~20% on most agentic tasks where cache hits are frequent.
**Why it matters:** Long Claude Code sessions that reuse context (prompt caching) become noticeably cheaper — no code changes required.

### [Opus 5.5 Fast Mode Now Generally Available](https://www.anthropic.com/news)
As of October 15, Opus 5.5 Fast Mode exited research preview. It provides full Opus 5.5 quality at faster output speeds, now production-ready.
**Why it matters:** Fast Opus 5.5 is viable for interactive Claude Code sessions that previously felt slow on Opus — worth re-evaluating if you've been defaulting to Sonnet 5.5 for speed reasons.

### [Codex CLI v0.164.0](https://help.openai.com/en/articles/11428266-codex-changelog)
Released October 23. Adds saved-prompt "presets" and inline arguments for `/model` and `/permissions`. v0.163.0 (Oct 15) added a searchable `/config` panel; v0.162.0 (Oct 8) added managed Git worktree tooling. Note: GPT-5.5 was retired from Codex for ChatGPT-authenticated sessions on October 14.
**Why it matters:** Presets reduce context-switching friction when toggling Codex between projects — useful if you keep Codex as a second opinion alongside Claude Code.

### [Cloudflare Workers KV Instant — Sub-2ms p99 Reads](https://blog.cloudflare.com/workers-kv-instant/)
Launched October 1. KV Instant, powered by Quicksilver v2, delivers p99 read latency under 2ms and ~250ms global replication across 300+ edge locations — over 100× faster than classic KV. Trade-offs: no metadata support, `list()` returns all matching keys without pagination.
**Why it matters:** For Workers-backed features in your stack (session caching, feature flags, edge config), KV Instant removes the latency excuse — live reads at the edge are now practical without a separate database layer.

### [Cloudflare KV Legacy API Routes Retired](https://developers.cloudflare.com/changelog/post/2026-07-15-kv-legacy-namespace-routes-deprecation/)
The old `/workers/namespaces/` API paths stopped working on **October 15, 2026**. Migration is a direct URL substitution: `/workers/namespaces/` → `/storage/kv/namespaces/`.
**Why it matters:** Any CI/CD scripts, Terraform configs, or tooling still using the old KV namespace API paths are already broken — audit your Cloudflare automation now.

## 🟡 Noteworthy

### [Gemini CLI v0.65.0 + v0.66.0-preview](https://github.com/google-gemini/gemini-cli/releases)
Both released October 20. v0.65.0 adds custom OTLP telemetry header support and filesystem traversal performance improvements (subtree pruning for ignore patterns, deferred recursive reads). v0.66.0-preview adds synchronized UI output and terminal scrollback fixes. v0.67.0 nightlies are active with daily builds through October 25.
**Why it matters:** The traversal performance improvements make Gemini CLI noticeably faster on large TypeScript/Next.js repos — relevant if you keep it available as a comparison tool.

### [PHP Critical Security Patches — October 21](https://developer.woocommerce.com/2026/10/21/php-security-release/)
PHP released fixes for two critical vulnerabilities. WooCommerce itself is not specifically affected, and Automattic-hosted sites are already protected — but all self-hosted PHP sites should update PHP immediately.
**Why it matters:** Bucktee customers running self-hosted WooCommerce on unpatched PHP are exposed. Worth a proactive advisory in your next plugin release notes or newsletter.

## 🧠 Takeaways

- **Haiku 5.5 + Sonnet 5.5 is now the optimal Claude Code cost profile.** Use Haiku 5.5 for subagent/compaction tasks and Sonnet 5.5 for primary coding — combined with the Sonnet 5.5 cache read price cut, this is materially cheaper than any configuration available last month.
- **Cloudflare KV just became a real-time datastore.** Sub-2ms p99 latency changes what's feasible at the edge — lightweight session state, live feature flags, and edge config are now viable in Workers without a separate database. Migrate your existing namespaces to opt in.
- **Two live production risks to audit immediately:** The Cloudflare legacy KV API routes are already dead (since Oct 15), and PHP's critical patches just landed. Both are easy to overlook in the model-release noise but can cause real outages for Bucktee customers.
- **Claude Code's versioning cadence continues to dwarf competitors.** The v2.1.x line has passed 309 patch releases; Codex CLI is at 0.164 and Gemini CLI at 0.65. The gap in iteration speed is widening, not closing — Claude Code's ecosystem of hooks, skills, and scheduled tasks has no real equivalent in either competing CLI.
