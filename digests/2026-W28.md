## 🔴 Critical

### [Claude Sonnet 5 Launches as Default Model in Claude Code](https://github.com/anthropics/claude-code/releases/tag/v2.1.197)

Claude Sonnet 5 shipped on June 30 (Claude Code v2.1.197) and is now the default model across all Claude plans including Claude Code, with a native 1M-token context window. Performance sits close to Opus 4.8 on coding and agentic benchmarks at a fraction of the price — introductory API pricing is $2/$10 per million input/output tokens through August 31, reverting to $3/$15 after that. Subagents and context compaction now inherit the extended thinking configuration automatically.

**Why it matters:** Claude Code sessions get near-Opus reasoning at Sonnet cost starting immediately. If you run background agents for Bucktee plugin work or Cloudflare Workers deploys, check your context window usage — Sonnet 5's 1M window changes what's worth compacting.

### [Six Claude Code Releases in Seven Days (v2.1.196 → v2.1.201)](https://github.com/anthropics/claude-code/releases)

A dense release week. The headline changes:

- **v2.1.198 (July 1):** Subagents now run in the background by default — Claude keeps working on the next turn while subagents execute. Claude in Chrome is generally available. Background agents now commit, push, and open draft PRs automatically when finishing code tasks. The new `/dataviz` skill provides chart and dashboard design guidance.
- **v2.1.200 (July 3):** `AskUserQuestion` dialogs no longer auto-continue; idle timeouts require explicit opt-in via `/config`. The "default" permission mode is now renamed **Manual** across the CLI, `--help`, VS Code, and JetBrains.
- **v2.1.196 (June 29):** `claude mcp list`/`get` no longer spawn untrusted servers — a silent security fix. Added clickable file attachments in chat (Cmd/Ctrl-click). Organization default models are now supported.

**Why it matters:** Background-by-default subagents is a workflow-level change — multi-step agentic tasks that previously blocked on each subagent now parallelize. The MCP trust fix matters immediately if you run `claude mcp list` in CI or scheduled digest runs like this one.

### [Gemini CLI Transitions to Antigravity CLI — Free Tier Ending](https://developers.googleblog.com/an-important-update-transitioning-gemini-cli-to-antigravity-cli/)

Google announced on June 18 that Gemini CLI and Gemini Code Assist IDE extensions are stopping service for Google AI Pro/Ultra and free individual users, redirecting them to Antigravity CLI and Antigravity 2.0. The GitHub repo (google-gemini/gemini-cli) continues publishing nightly builds and fixed a symlink directory-escape vulnerability in the memory import processor this week (July 2), but the product direction is clearly toward the commercial Antigravity platform.

**Why it matters:** If Gemini CLI is in any toolchain scripts or CI pipelines for the Bucktee plugin project, this is the time to decide whether to migrate to Antigravity CLI, swap it for Claude Code / Codex CLI, or pin the last stable free release (v0.45.0).

## 🟡 Noteworthy

### [@cloudflare/workers-types v5 Ships, Removes Dated Entrypoints](https://developers.cloudflare.com/changelog/post/2026-07-03-workers-types-v5/)

Released July 3, workers-types v5 drops all dated entrypoints (`@cloudflare/workers-types/2022-11-30`, `2023-03-01`, etc.) and exposes only the current runtime types. The recommended path going forward is generating per-Worker types with `wrangler types`, which locks types to your Worker's configured compatibility date.

**Why it matters:** Any TypeScript Worker or Pages Function with `@cloudflare/workers-types` in `package.json` will need to either upgrade to v5 and adopt `wrangler types`, or pin to v4 to avoid breaking type imports. Check Bucktee's Cloudflare integration if it uses dated entrypoints.

### [Windsurf Completes Rebranding to Devin Desktop; Cascade Hits EOL July 1](https://chatforest.com/builders-log/windsurf-devin-desktop-rebrand-devin-local-acp-builder-guide/)

Cognition's June 2 Windsurf → Devin Desktop rebrand settled this week with Cascade (the previous local agent) reaching end-of-life on July 1. The replacement, Devin Local, is a Rust rewrite claiming ~30% better token efficiency, with subagent support and native Agent Client Protocol (ACP) integration. The default interface now opens on an agent-management hub rather than the code canvas. Existing Windsurf settings and plans migrate automatically.

**Why it matters:** This is one of Claude Code's most direct competitors moving from "smart autocomplete IDE" to "agent-management hub" — the same direction Claude Code is heading with background agents and the agents panel. ACP adoption by JetBrains, Google, and GitHub is worth watching as a potential MCP alternative or complement.

### [Codex CLI v0.142.5: WebSocket Payloads No Longer Written to Trace Logs](https://github.com/openai/codex/releases/tag/v0.142.5)

The July 1 stable release addressed a security concern: full Responses API WebSocket request payloads (which can include prompts and credentials passed in tool outputs) were being written to local trace logs. The fix is now in the stable channel. Alpha v0.143.0 is actively cycling with multiple daily builds (five alpha tags this week).

**Why it matters:** If you log or ship Codex CLI trace files anywhere, verify you're on 0.142.5+ before those logs leave your machine. The active alpha cadence suggests a significant stable release is near.

## 🧠 Takeaways

- **Claude Sonnet 5 at $2/MTok intro pricing is likely the best value in the Claude lineup through August — use it now.** Near-Opus performance at well under Sonnet 4.6 cost is the kind of opportunity that narrows fast once introductory pricing ends. If you're building Bucktee AI features or Cloudflare Workers automations, target Sonnet 5 explicitly rather than inheriting whatever the default is post-September.

- **Background-by-default subagents in Claude Code v2.1.198 fundamentally changes session design.** Tasks that were sequential are now pipelined without any code change. The flip side: cost attribution matters more now — multi-subagent sessions can burn tokens faster than a single-stream session. Set the `Manual` permission mode (now the renamed default) to keep approval gates in place until you trust the agent's judgment on your specific workflows.

- **The Gemini CLI → Antigravity migration and the Windsurf → Devin Desktop rebrand both happened quietly.** Two of the major non-Claude CLI/IDE tools changed their fundamental identity this month. The ecosystem is consolidating around agent-management UX rather than code-editor UX — Claude Code's bet on the agent panel as the primary surface is looking correct in hindsight.

- **Cloudflare's workers-types v5 is a clean-up release but has a real migration cost.** Dropping dated entrypoints is the right call, but it means any Workers project that didn't already use `wrangler types` will hit a type-import error on next install. Audit now rather than discover it mid-deploy.
