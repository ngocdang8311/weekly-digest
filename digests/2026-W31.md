# Weekly AI & Tooling Digest — 2026-W31

*Week of 2026-07-20 to 2026-07-26*

## 🔴 Critical

### [Anthropic Launches Claude Opus 5](https://www.anthropic.com/news/claude-opus-5)
Opus 5 launches July 24 at $5/$25 per Mtok — half the price of Fable 5 — with a 1M-token context window and a new per-request effort setting (low/medium/high) that lets callers trade speed and cost against reasoning depth. Internal benchmarks show it outperforms Fable 5 on several coding and knowledge-work evaluations; it's now the default model on Claude Max and Claude Pro.
**Why it matters:** The combination of frontier-tier performance at Opus 4.8 pricing and the effort dial makes Opus 5 a strong default for agentic Claude Code tasks — swap it in via the model picker and tune effort per task type.

### [Claude Code v2.1.219: Nested Subagents to Depth 3 + Strict Sandbox Networking](https://code.claude.com/docs/en/changelog)
The July 24 release adds `CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH` (default 3, was 1) so workflows can fan out through multiple agent tiers without hitting an artificial ceiling. A new `sandbox.network.strictAllowlist` setting silently blocks all non-allowlisted hosts in sandboxed commands rather than prompting. Also ships: the `DirectoryAdded` hook fires when `/add-dir` registers a new repo root mid-session, useful for multi-repo workflows.
**Why it matters:** Depth-3 subagents enable real orchestration hierarchies in Claude Code workflows — a top-level agent delegating to specialist agents that each spawn their own tools; the strict network allowlist is a meaningful security tightening for sandboxed CI runs.

### [Claude Code v2.1.218: /code-review Runs as Background Subagent](https://code.claude.com/docs/en/changelog)
From July 22: `/code-review` no longer blocks the session — it spins off as a background subagent, keeping stacked slash commands as the review target. Also fixes Windows paths with `\u`-prefixed segments corrupting into CJK characters, and fixes `/ultrareview` failing on descriptive arguments.
**Why it matters:** Running `/code-review` asynchronously means you can queue a review and keep iterating; the Windows path fix matters if anyone on your team uses Claude Code on Windows.

### [Claude Voice Mode Expands to Opus and Sonnet with Connectors + 11 Languages](https://www.anthropic.com/news)
July 23 update ends the Haiku-only limitation: voice mode now runs on Opus and Sonnet models. Connectors integration lets voice interact with external tools linked to the user's Claude account. Eleven languages supported with mid-conversation language switching.
**Why it matters:** Voice mode on Opus is qualitatively different from Haiku — this is the update that makes it actually useful for extended coding-adjacent conversations and debugging walkthroughs.

### [Codex CLI v0.145.0: Streaming Voice V3 + Multi-Agent v2 Stable](https://releasebot.io/updates/openai/codex)
July 21 stable release: voice returns as streaming Realtime V3 with audio inputs and audio tool outputs in common local formats. The opt-in multi-agent v2 experience is now stable with configurable sub-agent models. Experimental paginated thread history enables efficient resume and search across past sessions. GPT-5.6 Sol/Terra/Luna context windows (272K) were corrected in an earlier July 18 fix.
**Why it matters:** Multi-agent v2 stable is the key signal — Codex now has a production-grade orchestration layer for splitting work across specialized sub-agents, closing a feature gap with Claude Code's workflow system.

## 🟡 Noteworthy

### ['WP2Shell' WordPress Core RCE Chain Actively Exploited — Patch to 7.0.2 / 6.9.5 / 6.8.6 Now](https://www.darkreading.com/cyberattacks-data-breaches/wp2shell-millions-wordpress-sites-remote-takeover)
CVE-2026-63030 (CVSS 9.8, REST API batch-route confusion) chained with CVE-2026-60137 (SQL injection via `author__not_in`) lets an unauthenticated attacker achieve full RCE on WordPress core 6.9.0–6.9.4 and 7.0.0–7.0.1 with no credentials required. Multiple security firms confirmed active in-the-wild exploitation within days of the July 17 disclosure. Fixed in 7.0.2, 6.9.5, and 6.8.6.
**Why it matters:** If Bucktee runs on an affected WordPress version, the site is trivially rootable today — upgrade immediately and verify Cloudflare WAF rules are in front of `/wp-json/batch/v1`.

### [Gemini CLI Transitioning to Antigravity CLI — Migration Support Active in July](https://developers.googleblog.com/an-important-update-transitioning-gemini-cli-to-antigravity-cli/)
Since June 18, Gemini CLI no longer serves Google AI Pro/Ultra and free-tier users; they must use Antigravity CLI (`agy` command, Go-based rewrite). Skills, hooks, subagents, and extensions carry over. Google Workspace / Gemini Code Assist Standard/Enterprise licenses are unaffected. July releases continue shipping migration commands and documentation.
**Why it matters:** If you have any Gemini CLI scripts in CI or tooling, the `gemini` binary no longer runs — audit before it silently fails on a scheduled job.

## 🧠 Takeaways

- **Anthropic is collapsing the price/performance curve fast.** Opus 5 at half Fable 5's price with comparable benchmarks means the frontier is no longer premium-only; the per-request effort dial is a better cost lever than model-tier selection.
- **Claude Code's agent depth going from 1 → 3 is architecturally significant.** Combined with the DirectoryAdded hook, you can now build orchestrators that dynamically discover and wire in repos mid-session — this changes what's possible in unattended automation.
- **The WP2Shell chain is unusually dangerous.** Pre-auth RCE on vanilla WordPress core (no plugin required) with active exploits circulating means every unpatched WordPress site is a ticking clock — don't treat this as a normal patch cycle.
- **Google's tool consolidation into Antigravity is still bumpy.** Free-tier and Pro users lost access a month ago and the migration story in July is still documentation-heavy — if Gemini CLI was part of your workflow, the switch isn't transparent.
