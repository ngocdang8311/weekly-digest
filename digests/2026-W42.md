# Weekly AI & Tooling Digest — 2026-W42

*Week of 2026-10-05 to 2026-10-11*

## 🔴 Critical

### [Anthropic Releases Claude Haiku 5.5 and Cuts Sonnet 5.5 Cache Prices](https://siliconangle.com/2026/10/07/anthropic-releases-claude-haiku-5-5-small-model-and-halves-sonnet-5-5-cache-read-prices/)
Launched October 7, Claude Haiku 5.5 (`claude-haiku-5-5`) prices in at $0.10/$0.50 per million input/output tokens — roughly 75% cheaper than Haiku 4.5 — with a 1M-token context window and a new effort setting. Simultaneously, Sonnet 5.5 cache-read prices were halved from $0.20 to $0.10 per million tokens. A caveat: Haiku 5.5 uses the newer tokenizer (introduced with Claude 4.7) which generates ~30% more tokens per prompt, so real-world savings may be smaller than headline rates suggest.
**Why it matters:** Haiku 5.5 is now the cheapest way to run Claude API calls in high-volume workflows — relevant if your Bucktee plugin or Cloudflare Workers touch the Claude API for any automated tasks. The Sonnet 5.5 cache-read cut benefits Claude Code sessions with large context, which is your primary daily-driver tool.

### [Claude Code v2.1.296: Subagent Auto-Compact, Plugin Marketplace Flag, and Mods](https://code.claude.com/docs/en/changelog)
The past week brought Claude Code to v2.1.296 (from ~2.1.287). The October 6 changelog added a `--marketplace` flag to `claude plugin install`, an `effort` parameter for the Agent tool, and a `CLAUDE_RETRY_DELAY` env var for throttled-request retries. The October 10 release added subagent auto-compact (agents compact their own context before hitting limits) and expanded Read support for larger files. Claude Mods (small TypeScript functions that ship inside plugins and customize Claude Code's behaviour) shipped on October 1 as the underlying mechanism for the plugin system.
**Why it matters:** Subagent auto-compact means long-running Claude Code workflows are less likely to fail mid-run due to context exhaustion. The `--marketplace` flag makes plugin discovery first-class — worth checking the marketplace for Cloudflare or TypeScript skills that could speed up Bucktee work.

### [⚠️ ACTION REQUIRED — Cloudflare Workers KV Legacy API Routes Die October 15](https://developers.cloudflare.com/changelog/post/2026-07-15-kv-legacy-namespace-routes-deprecation/)
The old REST routes at `/accounts/{id}/workers/namespaces/*` stop responding in **3 days**. The replacement is `/accounts/{id}/storage/kv/namespaces/*` — path-only change, same parameters and payloads. The binding API (`env.MY_KV.get()`) inside Workers is completely unaffected. At risk: curl scripts, Terraform `cloudflare_workers_kv_namespace` resources, older pinned Wrangler versions, and any CI/CD that manages KV namespaces directly via REST.
**Why it matters:** If any part of your Bucktee deployment pipeline or infrastructure-as-code touches KV namespace management via the REST API, it breaks on Tuesday. Audit now.

### [Cloudflare Workers KV Namespace Jurisdictions Now GA](https://developers.cloudflare.com/changelog/post/2026-10-02-kv-jurisdictions-ga/)
As of October 2, KV namespace jurisdictions (`eu`, `us`, `fedramp`) are generally available. A jurisdiction must be set at namespace creation and cannot be changed. Also shipped October 4: `ctx.cache.invalidate()` on the Cache API for programmatic cache invalidation (workerd v1.20261003.1).
**Why it matters:** If you have Cloudflare Workers handling EU users' data for Bucktee or any WooCommerce integration, you can now enforce data residency in KV at GA-stability without waiting for private beta access.

### [Codex CLI v0.161–0.162: GPT-6.1 Sol Default, Git Worktrees, GPT-5.5 Retiring](https://releasebot.io/updates/openai/codex)
Three releases this week: v0.161.0 (Oct 7) made GPT-6.1 Sol the default model in Codex; v0.162.0 (Oct 8) added managed Git worktree creation/listing tools and task-pinning in the Command Center; v0.162.1 (Oct 9) fixed a TUI crash with multi-line questions. GPT-5.5 is scheduled to be retired from Codex on October 14.
**Why it matters:** If you use Codex CLI alongside Claude Code, the switch to GPT-6.1 Sol is automatic — worth benchmarking it on your TypeScript/Next.js tasks to see if behaviour changed. The Git worktree tooling mirrors Claude Code's `isolation: "worktree"` pattern, suggesting convergence in how AI CLIs scope work.

## 🟡 Noteworthy

### [WordPress Core CVE-2026-87902 (CVSS 9.2) Actively Exploited — Patch Now](https://socprime.com/blog/cve-2026-87902-critical-wordpress-core-rce-flaw/)
A path-traversal flaw in WordPress page-template resolution (versions 4.7.0–7.1.1) was patched September 22 but exploitation began within hours of public disclosure. Separately, the "wp2shell" chain (CVE-2026-63030, CVE-2026-60137) enables unauthenticated RCE on WordPress 6.8.0–6.8.5 and is in CISA's Known Exploited Vulnerabilities catalog — WordPress forced auto-updates for affected versions.
**Why it matters:** If your Bucktee plugin's test/staging environments run any WP 6.8.x version, they may have been auto-updated; verify the installed version and confirm the plugin still works on the post-update WP. Unmanaged WooCommerce stores at clients need an urgent check.

### [Gemini CLI Still Pre-1.0 — Nightly v0.65.0 (Oct 10)](https://github.com/google-gemini/gemini-cli/releases)
Gemini CLI remains on nightly/preview tracks; v0.65.0-nightly.20261010 dropped October 10 with custom OTLP header support in telemetry and a fix for infinite OAuth retry loops. No stable channel release this week. Gemini 2.5 is reportedly shutting down October 16 — if you have any code calling `gemini-2.5-*` API IDs, migrate to Gemini 3.x before tomorrow.
**Why it matters:** Gemini CLI's continued nightly-only cadence compared to Claude Code's daily stable releases and Codex's weekly stable releases makes it harder to depend on for repeatable workflows. The Gemini 2.5 shutdown deadline is actionable.

## 🧠 Takeaways

- **Haiku 5.5 changes the economics of Claude-in-products.** At $0.10/M input tokens it's competitive with the cheapest commodity LLMs, while being a Claude 5-family model. If any part of Bucktee could benefit from an LLM call (category suggestions, description generation, search) the cost objection just got much smaller.

- **The Cloudflare KV API deprecation is the most time-sensitive item this week.** Three days. Any REST-based KV management code — Terraform, curl scripts, old Wrangler — breaks Tuesday without action. The binding API is safe.

- **Claude Code and Codex CLI are converging on the same architectural patterns** (worktrees, auto-compact, agent orchestration effort levels), suggesting these features are becoming table stakes. Claude Code is still shipping at a faster cadence and with deeper TypeScript plugin hooks.

- **WordPress's security situation this month is genuinely bad.** Two RCE chains in the wild, one in CISA KEV, means any WooCommerce storefront you maintain should be on the latest patched WP core before anything else this week.
