# Weekly AI & Tooling Digest — 2026-W38

*Week of 2026-09-07 to 2026-09-13*

## 🔴 Critical

### [Claude Code v2.1.265 & v2.1.269 — plugin folders, hook fixes, cache improvements](https://www.gradually.ai/en/changelogs/claude-code/)

Two releases this week (Sept 8 and Sept 11) landed quality-of-life and reliability fixes for Claude Code. v2.1.265 added support for pointing `--plugin-dir` at a folder of plugins where each child subfolder with a manifest is loaded automatically, enforced a 1 GB cap on tool-result disk saves, and fixed a bug where resumed subagents incorrectly moved hook context and preloaded skills out of the prompt prefix. v2.1.269 continued with targeted bug fixes and stability improvements.

**Why it matters:** The plugin-folder feature changes how you can structure and ship Claude Code plugins — including for Bucktee-adjacent tooling — without requiring manual per-plugin paths. The SubagentStart hook and prompt-cache resume fixes directly affect background agent workflows that are a core part of the Claude Code remote-session model.

### [Claude Fable 5.1 is now the default Fable model in Claude Code](https://platform.claude.com/docs/en/models/fable-5-1/overview)

Released September 1 (just before this week), Fable 5.1 is now the active default for Fable-mode sessions. The headline change is a **4× reduction in cache-read pricing** ($0.25/MTok vs ~$1/MTok previously), which Anthropic estimates cuts typical agentic workload costs by ~25% and highly agentic workflows by up to 45%. The model offers a 1M-token context window, 128K max output, adaptive thinking always on at high effort, and a June 2026 knowledge cutoff. Pricing is $10 input / $50 output per MTok (Batch API halves both).

**Why it matters:** If you run long background Claude Code sessions — code review, Bucktee plugin work, Cloudflare Workers scaffolding — the cache-read cost cut is real money. The 1M context also makes full-repo analysis practical without chunking.

### [Gemini CLI v0.59.0 stable ships SSRF fix for MCP OAuth + workspace trust hardening](https://github.com/google-gemini/gemini-cli/releases)

The v0.59.0 stable release (Sept 8) addressed a Server-Side Request Forgery (SSRF) vulnerability in MCP OAuth metadata discovery and strengthened workspace trust enforcement with fail-closed defaults. The accompanying nightly builds (v0.61.0-nightly, Sept 9–13) layered on additional security: prevention of indirect prompt injection via build-file modifications, NTFS path mitigation, sandbox isolation for settings directories, and envelope metadata provenance enforcement for untrusted tool outputs. A v0.60.0-preview.0 added RFC 9207 OAuth compliance and hardened path resolution in the extension loader.

**Why it matters:** If you run Gemini CLI alongside Claude Code (e.g., for comparison evals or redundancy), the SSRF fix in MCP OAuth is meaningful — MCP servers are a shared attack surface across all three CLI tools. The prompt injection via build files patch is particularly relevant if Gemini CLI touches any source-controlled config files in your repo.

## 🟡 Noteworthy

### [Cloudflare Workflows: completed instance state now retained 7 days (not 30) on paid plans](https://developers.cloudflare.com/changelog/product/workflows/)

Effective September 10, new Workflows on the Workers Paid plan retain completed and errored instance state for **7 days by default**, down from 30. The change reduces storage costs automatically; existing Workflows are unaffected. Separately, Cloudflare completed a rollout of read-latency improvements across all KV namespaces this week.

**Why it matters:** If you have Workers-based automation (e.g., long-running WooCommerce data syncs or Bucktee background jobs) that relies on polling completed Workflow state, your observability window just shrank to a week. Review any monitoring jobs that read Workflow history older than 7 days.

---

### [Cloudflare KV legacy REST API routes sunset: October 15 deadline](https://developers.cloudflare.com/changelog/post/2026-07-15-kv-legacy-namespace-routes-deprecation/)

Legacy KV namespace management routes (`/accounts/{id}/workers/namespaces/*`) were deprecated July 15 and **stop working October 15, 2026** — one month away. The replacement is a path-swap: `/accounts/{id}/storage/kv/namespaces/*`. Request parameters and response payloads are identical. Bindings accessed inside Worker scripts (`env.MY_KV.get(...)`) are unaffected.

**Why it matters:** Any CI/CD scripts, Wrangler wrappers, or admin tooling that call the KV REST API for namespace management need to be updated before October 15. Worth auditing your Workers deploy scripts now.

---

### [WooCommerce CVE-2026-3589 (CVSS 7.5): CSRF enables rogue admin account creation](https://www.sentinelone.com/vulnerability-database/cve-2026-3589/)

A CSRF vulnerability in WooCommerce 5.4.0–10.5.2 allows unauthenticated attackers to leverage a logged-in administrator's session to call non-store REST endpoints, potentially creating rogue admin accounts. CVSS score 7.5 (High). A separate DoS vulnerability (CVE-2026-48888) affects WooCommerce < 11.1.0.

**Why it matters:** If Bucktee runs on a site with WooCommerce ≤ 10.5.2, this is a direct exposure. Verify the installed WooCommerce version and update to 11.1.0+ to cover both CVEs. Also review any REST API endpoints your plugin exposes for missing nonce verification.

## 🧠 Takeaways

- **Cache economics just improved significantly.** Fable 5.1's 4× cache-read cut is the most impactful pricing change in months. For anyone running Claude Code in long agentic loops — the kind that accumulate large prompt prefixes across turns — the savings are automatic and substantial. No code change required; they flow through the existing API.

- **Security hardening is the theme of the week across all CLI tools.** Gemini CLI shipped an SSRF fix and prompt-injection prevention in the same week Claude Code fixed SubagentStart hook context leaks. MCP server trust boundaries are an active area of concern across the ecosystem — treat any MCP server that touches external data or build files as a potential injection surface.

- **The Cloudflare KV API deadline is real and close.** October 15 is 31 days away. The path swap is trivial, but finding every place the legacy route is called takes time. Run a grep across deploy scripts and any admin tooling now rather than discovering it mid-deploy.

- **WooCommerce is a consistent attack surface.** Two CVEs in 2026 affecting a wide version range confirms the pattern: sites running WooCommerce-adjacent plugins like Bucktee need a policy of staying current on WC core, not just the plugin itself.
