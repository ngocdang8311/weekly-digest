# Weekly AI & Tooling Digest — 2026-W47

*Week of 2026-11-10 to 2026-11-16*

## 🔴 Critical

### [Claude Code v2.1.322–v2.1.325](https://github.com/anthropics/claude-code/releases)
Four patch releases shipped Nov 10–13, with fixes across permissions, MCP, background sessions, and Code Mode. v2.1.319 (previous week) added an env-var flag to disable feature-flag fetching without disabling telemetry.
**Why it matters:** If you run Claude Code in CI or scripted contexts, the feature-flag env flag gives you a cleaner way to freeze behavior — worth checking the release notes before your next workflow update.

### [Claude Fable 5.2 & Mythos 5.2 Reported; Opus 4.8 Fast Mode Deprecated](https://github.com/jqueryscript/anthropic-claude-timeline)
Claude Fable 5.2 was reportedly released November 9 (unconfirmed by an official Anthropic source; treat as provisional) at $8/$40 per million input/output tokens, ~30% faster than 5.1 predecessors. Confirmed: Opus 4.8 fast mode was deprecated October 30 with removal on November 30; Anthropic recommends migrating to Opus 5.5.
**Why it matters:** The Opus 4.8 fast mode cutover is November 30 — if any Claude Code workflow, Anthropic SDK call, or Cloudflare AI Workers integration references that model ID, update now before it silently falls back to standard speed and cost.

### [Codex CLI 0.168.0 & 0.169.0](https://developers.openai.com/codex/changelog)
v0.169.0 (Nov 13) adds multiple side-chat tabs in the terminal workspace and task search in the agent command center. v0.168.0 adds model provider browsing from the configuration panel and OSC 777 terminal notifications with longer command-preview prompts.
**Why it matters:** Multi-tab side-chat is a meaningful workflow improvement if you run Claude Code and Codex CLI side by side; browsing model providers from config makes it straightforward to point Codex at non-OpenAI backends.

### [Cloudflare: Workflow Concurrency Limits + Workers Spending Alerts](https://developers.cloudflare.com/changelog/)
Two shipping items: Workflows now support per-workflow concurrency limits (requires Wrangler ≥4.127.0, Nov 10), and Workers/Durable Objects gained product-specific spending limits with email alerts (Nov 13).
**Why it matters:** Concurrency limits on Workflows are directly useful for background job pipelines on Cloudflare Workers; spending alerts add a safety net before unexpected traffic burns your budget.

### [Cloudflare: `request.signal` Disconnection Events Default On (effective Nov 17)](https://developers.cloudflare.com/changelog/product/workers/)
Workers with a compatibility date ≥ 2026-11-17 now receive client disconnection events through `request.signal` by default; a new module registry also activates for JS Workers at the same date. Opt-out is available via `disable_request_signal`.
**Why it matters:** A routine wrangler.toml date bump to today or later silently enables both changes — test long-running fetch handlers for graceful early-disconnect behavior before deploying.

## 🟡 Noteworthy

### [WooCommerce Stripe Gateway Critical: Plaintext Passwords in Order Data — Update to 11.2.0](https://developer.woocommerce.com/2026/11/11/stripe-gateway-security-update/)
Stores running Stripe Gateway 10.9.0 with classic checkout and Stripe Express buttons may have stored new customer passwords in plaintext inside order data. No confirmed exploits, but exposure cannot be ruled out; affected stores should check backups and prompt password resets.
**Why it matters:** High-severity and directly WooCommerce-adjacent — verify that any environment running Bucktee alongside a Stripe integration is on 11.2.0 (or the 11.1.2 patch branch) immediately.

### [WooCommerce 11.2.2 Security Release](https://developer.woocommerce.com/2026/11/04/woocommerce-11-2-2-release-notes/)
Security hardening across the Store API, REST API key authentication, checkout tax calculation for local pickup, and CSV importer validation. Includes a database update — run on staging before production.
**Why it matters:** REST API key auth hardening affects any plugin that calls the WC REST API programmatically; worth a compatibility check for Bucktee.

### [Gemini CLI v0.68.0 Stable + v0.69.0-preview](https://github.com/google-gemini/gemini-cli/releases)
v0.68.0 (Nov 10) is the new stable; v0.69.0-preview.0 ships the same day. Recent nightlies added a `models` command and `--list-models` flag for model discovery. A nightly banner notes Gemini CLI is not yet optimized for Gemini 4.
**Why it matters:** `--list-models` makes switching between Gemini model variants easier from the CLI — useful if you benchmark Gemini CLI against Claude Code on specific tasks.

## 🧠 Takeaways

- **Opus 4.8 fast mode removal on November 30 is a hard deadline.** Unlike most deprecations, there's no gradual fallback — it just switches to standard speed. Audit every Anthropic SDK call and Cloudflare AI Workers script that references this model ID before end of month.
- **WooCommerce had three security releases in 11 days, including a critical one.** The Stripe Gateway plaintext password bug is the highest-impact; Woo's own blog credits AI-driven vulnerability scanning for the accelerated disclosure pace — expect this release cadence to continue into 2027.
- **Cloudflare's November 17 compatibility date is a double behavior change.** Both `request.signal` and the new module registry activate together at the same date bump. This is the kind of "invisible upgrade" that breaks Workers in production when you're chasing unrelated CI failures — read the compat flags before bumping.
- **Claude Code remains clearly ahead of Codex CLI for complex agentic work.** Codex's multi-tab chat and provider-browsing are welcome UX improvements, but Claude Code's hooks system, tighter SDK integration, and richer MCP support keep it the stronger choice for the kind of workflows you're building.
