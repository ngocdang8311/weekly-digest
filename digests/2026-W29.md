## 🔴 Critical

### [Claude Code ships 6 releases in 7 days (v2.1.202–2.1.207)](https://github.com/anthropics/claude-code/releases)
An unusually dense release week: versions 2.1.202 through 2.1.207 landed between July 6 and July 11, touching background agents, MCP server reliability, auto mode, terminal rendering, and security. Highlights below.

**Why it matters:** This is your primary tool — each of these directly affects daily usage.

---

#### Auto mode lands on Bedrock, Vertex AI, and Foundry — no opt-in required
[v2.1.207 changelog](https://code.claude.com/docs/en/changelog) — Previously hidden behind `CLAUDE_CODE_ENABLE_AUTO_MODE`, auto mode is now on by default for all three cloud provider deployments. Bedrock and Vertex also switched to Claude Opus 4.8 as their default model. Disable via `disableAutoMode` in settings if needed.
**Why it matters:** If you're routing Claude Code through AWS Bedrock or GCP Vertex, you get smarter model routing with no config change — and Opus 4.8 by default.

#### Shell-injection fix: `${user_config.*}` in hook commands rejected
[v2.1.207](https://code.claude.com/docs/en/changelog) — Hook commands that interpolated `${user_config.*}` variables in shell form could allow injection; those patterns are now blocked outright. Also: plugin option values can no longer be read from project-level `.claude/settings.json` (user-level only).
**Why it matters:** If your Claude Code hooks or plugins use shell-form commands, audit them now — especially in multi-user or shared-repo setups like a WooCommerce plugin project.

#### `/doctor` upgraded to diagnose and fix, not just report
[v2.1.205](https://code.claude.com/docs/en/changelog) — `/doctor` (alias `/checkup`) now proposes and applies fixes: trims stale `CLAUDE.md` entries, flags slow hooks, surfaces disused MCP servers, and detects broken installations. The auto-updater also switched from memory-buffered downloads to streaming to disk, cutting peak memory use by ~400 MB.
**Why it matters:** Useful maintenance tool for keeping your Claude Code environment clean — especially `/doctor`'s new `CLAUDE.md` audit, which catches bloat that slows context.

#### macOS background agent 15–20s stall fixed
[v2.1.203](https://code.claude.com/docs/en/changelog) — A regression introduced in 2.1.196 caused a false low-memory detection that stalled background agent sessions when switching back to the agents view on macOS. Fixed; background agent work now carries over correctly instead of silently re-running the prompt.
**Why it matters:** If you run long background tasks in Claude Code on macOS and noticed sessions "restarting," this was the culprit.

### [Claude Sonnet 5 released — near-Opus at Sonnet pricing](https://www.anthropic.com/news/claude-sonnet-5)
Launched June 30, Sonnet 5 is now the default model for Free and Pro plans. It brings near-Opus 4.8 intelligence for coding and agentic tasks. Introductory pricing: **$2/M input, $10/M output** through August 31, 2026; bumps to $3/M in/$15/M out after that. Uses a new tokenizer vs. Sonnet 4.6. Cyber safeguards enabled by default (same as Opus 4.7/4.8).
**Why it matters:** Claude Code sessions on standard plans now run on a materially better model — relevant if you're testing workflows where you previously hit Sonnet 4.6 capability limits. Price hike after August 31 is something to budget for if you use the API directly.

### [Codex CLI v0.144.0 merges into ChatGPT desktop app](https://github.com/openai/codex/releases)
July 9: Codex is now embedded in the ChatGPT desktop app on macOS and Windows. New in the CLI: a **"writes app-approval mode"** that allows declared read-only actions automatically while prompting only for writes. MCP tools can now request authentication interactively without an experimental flag. Patch v0.144.1 fixed standalone installs breaking when GitHub returns compact release metadata.
**Why it matters:** OpenAI is consolidating Codex into the ChatGPT surface rather than treating it as a standalone developer tool. The writes-approval mode is the most directly useful feature — worth trying if you want a lighter-touch permission model than full auto.

### [Gemini CLI ends free service; replaced by closed-source Antigravity CLI](https://github.com/google-gemini/gemini-cli/discussions/27274)
On June 18, Google stopped serving Gemini CLI requests for all free, Google AI Pro, and Ultra users. The replacement is **Antigravity CLI** (`agy`), a closed-source Go binary announced at Google I/O 2026. It supports async multi-agent workflows that the TypeScript Gemini CLI architecture couldn't, but drops the Apache 2.0 open-source model. The `google-gemini/gemini-cli` repo continues receiving nightly builds (v0.50.0 stable July 8; v0.51.0-preview.0 same day with a symlink directory-escape security fix), but Google's investment has clearly moved to Antigravity. The community contributed 6,000+ merged PRs to the now-deprecated open project.
**Why it matters:** If Gemini CLI was in your toolchain (even occasionally), it no longer works unless you're on a Code Assist Standard/Enterprise license. The shift to a closed-source Go binary inverts everything that made the tool attractive. Consider this a resolved question: your Gemini CLI experiments are done unless you buy into the enterprise tier.

## 🟡 Noteworthy

### [Cloudflare: new Durable Objects can no longer use KV-backed storage](https://developers.cloudflare.com/changelog/)
Effective July 9: accounts without an existing KV-backed Durable Object namespace can no longer create new ones. All new Durable Objects must use the SQLite storage backend. Accounts with at least one existing KV-backed namespace retain the ability to create more for now.
**Why it matters:** If you're building new Workers with Durable Objects — likely for Bucktee or Cloudflare-hosted features — SQLite is now the only path. SQLite DO has been the recommended default since GA in 2024; this just formalizes it.

### [WooCommerce: Customer Reviews plugin XSS (CVE-2026-13771, CVSS 6.4)](https://freshysites.com/security-bulletins/customer-reviews-for-woocommerce-plugin-vulnerability-cve-2026-13771/)
Published July 9. The "Customer Reviews for WooCommerce" plugin stores unescaped content from the `color` shortcode attribute, allowing a contributor-level user to inject scripts that execute for any visitor viewing the affected page. Severity medium (CVSS 6.4) — exploitable by any account that can create content.
**Why it matters:** WooCommerce stores typically allow guest reviews or editor-level contributors. If Bucktee's hosts use this plugin alongside WooCommerce, it's an exploitable XSS vector. Check if any sites you maintain have it installed.

## 🧠 Takeaways

- **Claude Code velocity is exceptional.** Six releases in seven days — most touching stability and security — signals that Anthropic is treating the CLI as a product with a real release cadence, not a research artifact. The security fixes (hook injection, remote settings consent) matter for production use.
- **Sonnet 5's August 31 pricing cliff is worth noting.** The introductory $2/M rate is a 33% discount off the post-August price. If you're building anything that calls the API at volume, lock in your architecture benchmarks now before the price shifts.
- **Google's Gemini CLI → Antigravity pivot is a signal, not just a product change.** Accepting 6,000 community PRs on an Apache-licensed project then replacing it with a closed Go binary reads as strategy: let OSS grow the community, capture it in a proprietary product. Apply this lens to any AI CLI tool without a strong commercial backing.
- **Cloudflare's KV-backed Durable Objects sunset is accelerating.** If any of your Workers or Pages projects still prototype with KV-backed DOs, migrate now before the window closes entirely.
