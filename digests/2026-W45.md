# Weekly AI & Tooling Digest — 2026-W45

*Week of 2026-10-27 to 2026-11-02*

## 🔴 Critical

### [Claude Mods: Plugins Now Modify Deeper Behavior](https://code.claude.com/docs/en/changelog)
Around October 1, Anthropic introduced Claude Mods, enabling plugins to alter core Claude Code behavior — including a built-in "You Should Know" mod that uses a side agent to surface things you or Claude might miss. Forked subagents became the default in v2.1.302 (Oct 16/17), and v2.1.312 (Oct 27) added `oidc.user_id_claim` for the Claude apps gateway and a fullscreen click-to-send action.
**Why it matters:** If you build or use Claude Code plugins for your Bucktee workflow, Mods unlock a new tier of customization beyond existing hooks; the "You Should Know" mod is available immediately on update.

### [Claude Code v2.1.310: Sandbox Hardened](https://code.claude.com/docs/en/changelog)
v2.1.310 (Oct 23) prevents shell startup files from running outside the sandbox and blocks `--mcp-config` modification by sandboxed commands. A new env var (`CLAUDE_CODE_RETRY_WATCHDOG_MAX_USAGE_LIMIT_WAIT_MS`) lets unattended retry mode exit early if a usage-limit reset is too far away.
**Why it matters:** If you run Claude Code in automated/CI-style workflows for Cloudflare Workers deploys, the sandbox hardening closes a startup-file injection vector.

### [Claude Haiku 5.5 Released — 1M Context, Adaptive Thinking](https://www.anthropic.com/transparency)
Launched October 7, Haiku 5.5 is Anthropic's fastest small model: 1M-token context, up to 128K output tokens, and adjustable effort/adaptive thinking built for high-volume subagent work. Simultaneously, Sonnet 5.5's prompt-cache read price was cut from $0.20 → $0.10 per million tokens.
**Why it matters:** Haiku 5.5 is purpose-built for subagent-heavy orchestration; if you're building Claude Agent SDK automations around Bucktee or Cloudflare Workers, this is the cheapest capable tier yet.

### [Opus 4.8 Fast Mode Deprecated — Removal November 30](https://platform.claude.com/docs/en/release-notes/overview)
Anthropic deprecated fast mode for Claude Opus 4.8 on October 30, with hard removal on November 30, 2026. Opus 5.5 is the designated replacement and already costs ~40% less on typical workloads than Opus 5.
**Why it matters:** Any code or prompts referencing the `claude-opus-4-8` fast-mode endpoint will break in under four weeks — audit and migrate now; Opus 5.5 is cheaper anyway.

### [Cloudflare KV: Legacy Routes Dead, Jurisdictions GA, KV Instant Private Beta](https://developers.cloudflare.com/changelog/product/kv/)
Three KV milestones in October: (1) The old `/workers/namespaces/` API routes stopped working October 15 — migration target is `/storage/kv/namespaces/`. (2) Namespace jurisdictions (`eu`, `us`, `fedramp`) went GA on October 2, set at creation time only. (3) "KV Instant" (Quicksilver-backed) entered private beta with reported p99 reads of 1.6 ms vs 287 ms for classic KV.
**Why it matters:** If any of your Bucktee or Workers integrations still call the old KV namespace routes, they are broken right now. KV Instant is worth joining the beta if your Workers need sub-2ms key reads.

## 🟡 Noteworthy

### [WooCommerce CVE-2026-106608: Privilege Escalation (CVSS 7.2 High)](https://app.opencve.io/cve/CVE-2026-106608)
A privilege escalation flaw affects WooCommerce core 9.8.0–11.1.2; fix is updating to 11.2.0+. No confirmed active exploitation reported yet, but NVD enrichment is still pending.
**Why it matters:** Bucktee is a WooCommerce-adjacent plugin — any test or production installs below 11.2.0 are exposed to a high-severity escalation path; update this week.

### [GitHub Copilot Adds 4 AI Models (Oct 20)](https://devtoollab.com/blog/best-ai-coding-assistants)
GitHub Copilot reportedly added four additional AI models to its backend on October 20, 2026, and shipped an Agent Host system with Dev Container agent support on September 16.
**Why it matters:** Marginal for heavy Claude Code users, but signals Copilot is catching up on multi-model flexibility that was previously a differentiator.

### [Codex CLI v0.166.0; Signed Windows Installer in v0.162](https://developers.openai.com/codex/changelog)
Codex CLI reached v0.166.0 (latest on npm as of this week). v0.162.0 (Oct 8) added a signed PowerShell installer for Windows; no major feature announcements in the past 7 days specifically.
**Why it matters:** If you maintain Windows dev environments, the signed installer removes UAC friction on CLI updates.
