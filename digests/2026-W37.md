# Weekly AI & Tooling Digest — 2026-W37

*Week of 2026-08-31 to 2026-09-06*

## 🔴 Critical

### [Claude Fable 5.1 + Mythos 5.1: Same price, 75% cheaper cache reads](https://www.anthropic.com/claude-fable-and-mythos-5-1)
Anthropic shipped `claude-fable-5-1` and `claude-mythos-5-1` on September 1. Headline pricing is unchanged at $10/$50 per million tokens, but cached input reads drop from $1.00 to $0.25 per million — a 75% reduction. Fable 5.1 is general availability; Mythos 5.1 is the same model with tighter safeguards, restricted to vetted cybersecurity and life-sciences programs.
**Why it matters:** Agentic Claude Code runs — especially those that re-use large system prompts or skill context across many turns — get meaningfully cheaper overnight with no code changes required.

---

### [Claude Code v2.1.257: Fable 5.1 ships as the new default model](https://github.com/anthropics/claude-code/releases)
The Sept 1 release bakes `claude-fable-5-1` in as the default, expands the effective context to 1M tokens, and adds time-format configuration (12/24-hour, UTC, strftime). A same-day v2.1.258 hotfix restored macOS 12 compatibility.
**Why it matters:** If you haven't pinned a model in your project's `CLAUDE.md`, you're already on Fable 5.1 — check your spend dashboards and confirm the larger context window isn't silently increasing output token costs on verbose tasks.

---

### [Claude Code v2.1.259: `managedMcpServers` for orgs + `--permission-prompts none`](https://github.com/anthropics/claude-code/releases)
Organizations can now push HTTP/SSE MCP servers to every user via a `managedMcpServers` managed setting. `--permission-prompts none` suppresses all permission dialogs for unattended/headless hosts. GitLab merge-request links now display as `MR !N` in tool summaries.
**Why it matters:** `--permission-prompts none` is a direct enabler for automated CI pipelines or scheduled Claude Code runs; `managedMcpServers` lets teams standardize tool access without individual setup.

---

### [Claude Code v2.1.260: `/diff` panel + prompt cache miss diagnostics](https://github.com/anthropics/claude-code/releases)
A side-by-side diff panel (toggle with `/diff`) lands in full-screen mode. Cache miss diagnostics surface when context changes invalidate the prompt cache. Auto-compact is now enabled for 1M-context models.
**Why it matters:** Cache miss diagnostics finally make it visible when your session is silently burning full input costs — useful for tuning agentic workflows that should be cache-hitting.

---

### [Claude Code v2.1.261: `/skill-doctor`, `PreModelSwitch`/`PostModelSwitch` hooks, 128K output caps](https://github.com/anthropics/claude-code/releases)
Organization policy diagnostics land in `/status` and `claude doctor`. `/skill-doctor` reports unused skills. `bashOutputMaxChars` and `taskOutputMaxChars` can now be raised to 128K. New **PreModelSwitch** and **PostModelSwitch** hook events fire whenever the active model changes.
**Why it matters:** The new hook events make it possible to, e.g., log or block model switches in automated sessions; `/skill-doctor` is immediately useful if you maintain custom skills for Bucktee or other projects.

---

### [Cloudflare "Agents Week": Access for Workers, gRPC, unified AI Gateway](https://blog.cloudflare.com/agents-week-review-august-2026/)
Cloudflare's August Agents Week shipped several Worker-relevant features now in production: Access policies can be attached directly to a Worker (applies to all routes, previews, workers.dev — no separate config); Workers now accept inbound TCP connections via Spectrum with native gRPC support; Workers AI and AI Gateway merged into a single control plane with unified bindings; `wrangler dev` now emits structured traces per request for agent-friendly debugging; and Kitesurf (a stateless browser running on Workers) is available for agentic scraping workloads.
**Why it matters:** If you're building any AI-backed tooling on Workers — or considering offloading Bucktee plugin tasks to a Worker endpoint — the Access-for-Workers feature eliminates a whole class of auth plumbing, and unified AI Gateway gives you observability across model calls for free.

---

### [Cloudflare Workers KV legacy API routes deprecated — deadline October 15](https://developers.cloudflare.com/changelog/product/kv/)
The old KV routes at `/accounts/{account_id}/workers/namespaces/*` were deprecated July 15 and stop working October 15, 2026. Any Wrangler config or direct API calls using the legacy path need migration to the new routes.
**Why it matters:** Six weeks remain. If any of your Workers or CI scripts hit the KV API directly (not via Wrangler bindings), check now — a silent 404 in October will not be fun to debug.

## 🟡 Noteworthy

### [Gemini CLI v0.58.0 stable + v0.59.0-preview: MCP SSRF hardening](https://github.com/google-gemini/gemini-cli/releases)
v0.58.0 (stable, Sept 1) fixes symlink evaluation in ignore paths and Docker isolation on macOS. The v0.59.0 preview adds SSRF prevention in MCP OAuth metadata discovery and enforced fail-closed workspace trust. **Migration note:** Google has unified its dev tooling into "Antigravity CLI"; Gemini CLI free tier stopped serving requests in June 2026.
**Why it matters:** If you run Gemini CLI for cross-model comparisons alongside Claude Code, plan the migration to Antigravity CLI before the tool becomes unavailable.

---

### [Codex CLI v0.153.x: Vim-mode undo/redo, marketplace plugin CLI, per-thread token budgets](https://releasebot.io/updates/openai/codex)
This week's Codex CLI releases are mostly polish: vim-mode gets proper undo (`u`) and redo (`Ctrl+R`), the `/plugins` command now organizes marketplace plugins into curated/workspace/shared sections, and rollout token budgets now track usage across agent threads.
**Why it matters:** Incremental housekeeping — nothing breaking. Worth a version bump if you use Codex CLI alongside Claude Code for comparison testing.

---

### [WooCommerce Square plugin IDOR: unauthenticated CCF token exposure (≤ v5.1.1)](https://wpscan.com/plugin/woocommerce-square/)
An Insecure Direct Object Reference in the Square for WooCommerce plugin's `get_token_by_id` function allows unauthenticated attackers to read arbitrary "credit card on file" token values and potentially charge them. Affects all versions up to 5.1.1.
**Why it matters:** If Bucktee or any adjacent WooCommerce install uses Square payments, patch immediately — unauthenticated payment-token exposure is critical severity regardless of PCI scope.

## 🧠 Takeaways

- **Cache reads are now the real Claude cost lever.** Fable 5.1 cuts cache hit cost 75%, and the new cache-miss diagnostics in Claude Code let you see when you're paying full price. The combination makes prompt-cache tuning a high-ROI activity this week — especially for agentic loops with large shared context.
- **Claude Code is accumulating serious CI/CD surface area.** `--permission-prompts none`, `managedMcpServers`, `PreModelSwitch`/`PostModelSwitch` hooks, and 128K output caps all shipped in one week. This is a tool trending toward unattended automation, not just interactive assistance.
- **Cloudflare is quietly becoming an AI-native platform.** Unified AI Gateway + Workers AI, Access-for-Workers, Kitesurf, and structured traces landed in a single Agents Week. If you're building on Workers, the platform is now opinionated about AI workloads in a way it wasn't six months ago.
- **Gemini CLI's free tier is gone and the tool is being superseded.** Don't rely on it for anything production-adjacent — migrate to Antigravity CLI or treat Gemini access as API-only going forward.
