# Weekly AI & Tooling Digest — 2026-W33

*Week of 2026-08-03 to 2026-08-09*

## 🔴 Critical

### [Claude Code v2.1.224: Self-Hosted Runner + Cross-Session Messaging](https://github.com/anthropics/claude-code/releases/tag/v2.1.224)
Claude Code shipped 5 releases this week (v2.1.222–v2.1.226). The standout addition in v2.1.224 (Aug 7) is `claude self-hosted-runner` for Team and Enterprise plans, letting you run the agent loop inside your own infrastructure. The same release adds cross-session `SendMessage` so agents can message each other across machines (macOS/Linux), an `archive` plugin source for installing plugins from zip-over-HTTPS with SHA-256 pinning, and removes the 200-subagent-per-session cap.
**Why it matters:** Self-hosted runner means you can deploy Claude Code agents inside your own network or CI environment rather than Anthropic's cloud — critical for enterprise Bucktee work where data residency or VPC isolation matters.

### [Claude Code v2.1.223: Bash Permission Bypass Security Fix](https://github.com/anthropics/claude-code/releases/tag/v2.1.223)
v2.1.223 (Aug 6) patched a Bash permission bypass where crafted commands could hide portions of their content from permission checks, and a second bypass via padded tabs/Unicode in permission prompts. Workflow scripts using dynamic `import()` outside the sandbox were also blocked.
**Why it matters:** If you run Claude Code in auto mode or with broad Bash permissions, these were exploitable to silently execute commands outside your allow-list — update immediately.

### [Claude Code v2.1.225: Spend-Limit Warnings + Workspace Trust for Agents](https://github.com/anthropics/claude-code/releases/tag/v2.1.225)
v2.1.225 (Aug 8) adds gateway spend-limit display in usage warnings (with reset time), a workspace trust prompt before running `claude agents` in untrusted directories, and fixes for MCP OAuth 401 errors on macOS after keychain read timeouts.
**Why it matters:** The workspace trust gate prevents a malicious repo from silently spawning agents when you `cd` into it — relevant if you work with third-party plugins or WooCommerce vendor code.

### [Codex CLI v0.147.0: `--approve-for-me` Flag + MCP 2026-07-28 Protocol](https://github.com/openai/codex/releases/tag/v0.147.0)
Codex CLI v0.147.0 (Aug 7) ships `--approve-for-me` for automatically reviewed approvals in CI, opt-in MCP 2026-07-28 protocol (paginated discovery, multi-round requests, non-blocking startup), bearer-token redaction from displayed commands and replayed history, and cached web search. **Note:** GPT-5.4 and GPT-5.4 mini will be removed from Codex for ChatGPT-authenticated users on August 31.
**Why it matters:** If you run Codex in CI pipelines alongside Claude Code, the new MCP protocol aligns with the version Claude Code also supports, reducing interoperability friction. The Aug 31 model deprecation requires action if you're on GPT-5.4 in Codex.

### [Cloudflare Workers KV: Legacy API Deprecated, Remote Bindings Now GA](https://developers.cloudflare.com/changelog/product/kv/)
The legacy KV API routes under `/accounts/{id}/workers/namespaces/*` were deprecated July 15 and **stop working October 15, 2026** — migrate to `/accounts/{id}/storage/kv/namespaces/*`. Separately, remote bindings (connect to KV, D1, R2, etc. during `wrangler dev`) are now GA without an experimental flag in Wrangler, Vite, and Vitest. KV also completed a storage infrastructure overhaul this cycle, cutting P95 read latency from ~150 ms to ~50 ms.
**Why it matters:** Any scripts or tooling (deploys, Bucktee plugin CI) hitting the old KV API routes will hard-fail in October. Remote bindings GA means you can now test Bucktee's Workers integration locally against live KV data without a full deploy cycle.

## 🟡 Noteworthy

### [WooCommerce Subscriptions 9.1.0: Critical Privilege Escalation Patched](https://developer.woocommerce.com/2026/08/05/security-update-wc-subscriptions/)
WooCommerce patched a critical vulnerability in Subscriptions (all versions prior to 9.1.0) where an unauthenticated user could assume site control — effectively admin-level privilege escalation. Disclosed Aug 5 via internal security review; no confirmed exploitation in the wild. Update to 9.1.0 immediately.
**Why it matters:** If Bucktee or any managed site uses WooCommerce Subscriptions, this is a critical patch — admin takeover via unauthenticated request is the worst class of WP vulnerability.

### [Stripe for WooCommerce 10.8.5: Webhook Handling Security Fix](https://developer.woocommerce.com/2026/08/06/security-update-for-stripe-for-woocommerce/)
A security update patched an issue in Stripe for WooCommerce (versions 9.7.0–10.8.4) where a flaw in webhook handling could render an affected store unavailable. Patched in 10.8.5 (Aug 5) with backports to older release lines. No evidence of exploitation; no payment data exposed.
**Why it matters:** Stripe is a near-universal WooCommerce payment gateway — worth verifying all stores are on a patched version (10.8.5 or a patched backport for their release line).

### [Gemini CLI → Antigravity CLI: Migration Now Past the June 18 Deadline](https://developers.googleblog.com/an-important-update-transitioning-gemini-cli-to-antigravity-cli/)
Google shut down Gemini CLI for free/Pro/Ultra individual tiers on June 18, 2026, replacing it with Antigravity CLI (`agy`). The Gemini CLI repo is still active (v0.54.4 stable shipped Aug 7) but only serves enterprise/API-key users. Antigravity CLI is a Go-compiled agent-first platform with subagents, sandbox isolation, and a plugin import path from Gemini.
**Why it matters:** If you were evaluating Gemini CLI as a Claude Code alternative, the product has now effectively split: enterprise users get continued `gemini-cli` builds; everyone else is on `agy` — a more opinionated, agentic-first tool closer to Claude Code in design.

### [Claude Sonnet 5 Introductory Pricing Ends August 31](https://www.anthropic.com/news/claude-sonnet-5)
Released June 30, Sonnet 5 is priced at $2/$10 per million input/output tokens through August 31 — after which it rises to $3/$15. Sonnet 5 matches Opus 4.8 capability levels on reasoning, tool use, and coding benchmarks at the lower price point, with a 1M-token context window.
**Why it matters:** If you're building agentic workflows on Sonnet 5 (or budgeting for them), the pricing baseline changes in ~3 weeks. Lock in test runs and API cost estimates before the transition.

## 🧠 Takeaways

- **Claude Code is accelerating on the enterprise/security axis.** Self-hosted runner, workspace trust prompts, spend-limit controls, and two security fixes in one week signal Anthropic is hardening the tool for production team deployments — not just developer laptops. If you haven't reviewed your auto-mode permission settings lately, this week's security fixes are a good prompt to do so.

- **The Cloudflare KV migration deadline is real and close.** October 15 is 9 weeks out. Any automation or deploy tooling hitting `/workers/namespaces/*` routes will break silently then. Audit now; the fix is a URL swap, not a logic change.

- **WooCommerce had a genuinely bad security week.** Two separate critical advisories in two days (Subscriptions + Stripe) — both from internal reviews, so no known exploits, but the blast radius of admin takeover via unauthenticated request is severe enough to treat these as P0 patches.

- **The "Gemini CLI" era is over for individual users.** Google's Antigravity pivot is a bet that the next generation of coding tools is multi-agent and infrastructure-embedded, not prompt-in-terminal. Anthropic's Claude Code self-hosted runner this week is the same architectural move. The era of single-binary CLI tools is giving way to agent orchestration platforms with sandboxed subagents — worth factoring into how you evaluate and integrate AI tooling going forward.
