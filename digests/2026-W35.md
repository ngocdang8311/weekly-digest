# Weekly AI & Tooling Digest — 2026-W35

*Week of 2026-08-18 to 2026-08-24*

## 🔴 Critical

### [Claude Code v2.1.234–239: Cost Estimates, Security Hardening, 100+ Fixes](https://code.claude.com/docs/en/changelog)
Seven releases dropped between August 17–21. The headline features: a built-in `/cost` command with a `--max-budget-usd` budget cap, an `ANTHROPIC_DEFAULT_MODEL` env var to set the default model per shell/machine, automatic session continuation when claude.ai usage limits reset, and a `/claude-api upgrade` helper for migrating Python projects from `anthropic` 0.x to 1.x. Security highlight: Windows NT-namespace path rejection (`\??\`) to block NTLM credential leaks — useful if you ever run Claude Code in mixed environments.

**Why it matters:** The budget cap (`--max-budget-usd`) and cost display are direct answers to runaway spend in long agentic sessions — exactly what you hit doing Bucktee plugin work or Cloudflare Workers automation. The 0.x→1.x Python upgrade helper also matters if any of your Anthropic SDK integrations are still on the old API.

### [Sonnet 5 Pricing Made Permanent at $2/$10 per M Tokens](https://releasebot.io/updates/anthropic/claude)
Anthropic has permanently locked in the Sonnet 5 introductory pricing of $2 per million input tokens and $10 per million output tokens, canceling the scheduled September 2026 increase to $3/$15.

**Why it matters:** Sonnet 5 is the sweet spot for agentic coding tasks — fast enough for interactive use, capable enough for TypeScript/React refactors. Locking in this price makes it safe to build cost projections around without hedging.

### [Voice Mode Expands to Opus 5 and Sonnet 5](https://www.anthropic.com/news/claude-sonnet-5)
Voice mode, previously limited to Haiku, now runs on all Claude 5 models including Opus 5 and Sonnet 5, and has access to connected tools (Gmail, Slack). Language support is also significantly expanded.

**Why it matters:** If you're prototyping any voice-driven feature in a Next.js app or integrating Claude into a client-facing WooCommerce workflow, the jump in capability here is substantial.

### [Codex CLI v0.149.0: Agent Dashboard + Session Queuing](https://www.havoptic.com/tools/openai-codex)
The August 20 release adds an interactive agents dashboard (search, start, rename, stop tasks with configurable shortcuts), `/cd`/`/pwd`/`/cwd` commands for managing working directory mid-session, and a `codex queue` command for sending messages to running local or remote sessions. MCP SDK bumped to 3.0.0, Ratatui to 0.30.2.

**Why it matters:** Session queuing and the agent dashboard close the gap with Claude Code's multi-session model. If you're running Codex CLI alongside Claude Code, the UX is converging.

### [Google Sunsets Gemini CLI → Migrates to "Antigravity CLI"](https://developers.googleblog.com/an-important-update-transitioning-gemini-cli-to-antigravity-cli/)
Google is retiring the standalone Gemini CLI and consolidating its developer tooling into a new multi-agent platform called **Antigravity**, with Antigravity CLI as the replacement. Gemini Code Assist for individual tiers stopped serving requests June 18; migration to the new platform is required. Gemini 3.1 Pro and Gemini 3.0 Flash are now available in VS Code/IntelliJ agent mode as part of the transition.

**Why it matters:** If Gemini CLI is part of your workflow alongside Claude Code and Codex CLI, you need to migrate. The rebrand suggests Google is making a bigger architectural bet on multi-agent orchestration rather than a single CLI tool — worth watching to see if Antigravity CLI becomes a genuine competitor.

## 🟡 Noteworthy

### [Cloudflare Workers + Access Integration: Per-Worker Policy Enforcement](https://developers.cloudflare.com/changelog/post/2026-08-14-workers-access/)
Workers can now have an Access policy attached directly to the Worker — all routes and preview URLs automatically inherit the protection without manual per-domain rules. A new "all Workers private by default" setting also exists for teams wanting blanket sign-in enforcement.

**Why it matters:** If you're building internal tools on Cloudflare Workers (e.g., Bucktee plugin admin endpoints, WooCommerce webhook handlers), you can now lock them behind Access with a single policy rather than managing route-level rules.

### [DeepSeek V4 Pro + Flash on Workers AI (1M Token Context)](https://developers.cloudflare.com/changelog/product/workers-ai/)
DeepSeek V4 Pro and Flash are now available on Workers AI with a 1,048,576-token context window. Flash is the faster/cheaper sibling aimed at agentic tasks.

**Why it matters:** Running large-context inference at the edge via Workers AI is now viable for complex document processing or long-conversation agents — no need to call a centralized API from a Worker.

### [CVE-2026-8457: WooCommerce Social Login Authentication Bypass (CVSS 9.8)](https://freshysites.com/security-bulletins/woocommerce-social-login-plugin-vulnerability-cve-2026-8457/)
Disclosed August 1. Unauthenticated attackers can log in as any user — including admins — on sites running WooCommerce Social Login ≤2.8.7. The Apple login handler fails to validate identity tokens against Apple's public keys, making it trivial to forge a token with any email address.

**Why it matters:** Critical for any WooCommerce store using social login. If Bucktee's target users run this plugin, flag it for customers — a 9.8 with public PoC available is patch-immediately territory.

### [CVE-2026-18391: WooCommerce Subscriptions PHP Object Injection (< 9.1.0)](https://freshysites.com/security-bulletins/woocommerce-subscriptions-plugin-vulnerability-cve-2026-18391/)
Published August 12. PHP Object Injection via WooCommerce Subscriptions when High-Performance Order Storage (HPOS) is enabled. Fixed in 9.1.0.

**Why it matters:** Subscriptions is one of the most widely deployed WooCommerce extensions. If HPOS is on (which WooCommerce now pushes by default), this is an active risk — update immediately.

## 🧠 Takeaways

- **Claude Code is now a budget-aware infrastructure tool.** The `--max-budget-usd` cap and `/cost` command signal that Anthropic is treating Claude Code as something teams deploy at scale, not just individuals using interactively. Design your automation scripts to pass budget limits explicitly.

- **Google's CLI pivot matters more than it looks.** Sunsetting Gemini CLI in favor of "Antigravity" is a bet that multi-agent orchestration beats single-model terminal tools. If Antigravity CLI ships strong MCP support, the three-way race (Claude Code, Codex CLI, Antigravity) will look very different by Q1 2027.

- **Cloudflare's AI edge play is serious.** 1M-token context DeepSeek on Workers AI plus Access-native Worker protection in the same week suggests Cloudflare is building toward a full AI application platform — compute, inference, and auth — without leaving the edge. Worth evaluating for any agentic backend you'd otherwise build on a VPS.

- **WooCommerce supply-chain risk is rising.** Two high-severity CVEs in one week, both in first-party or widely-installed adjacent plugins, is a pattern. For Bucktee users, a plugin-audit checklist for Subscriptions and Social Login would be a low-effort, high-trust customer touchpoint.
