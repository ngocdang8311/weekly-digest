# Weekly AI & Tooling Digest — 2026-W32

*Week of 2026-07-27 to 2026-08-02*

## 🔴 Critical

### [Claude Opus 5 Launches — New Flagship at Same Price](https://www.anthropic.com/news/claude-opus-5)
Anthropic released Claude Opus 5 on July 24, replacing Opus 4.8 at the same $5/$25 per million token pricing. It features a 1M-token context window, xhigh reasoning effort mode, and new SOTA results on coding evals (Frontier-Bench, GDPval-AA) — beating Fable 5 on those specific benchmarks while undercutting it on cost.
**Why it matters:** Opus 5 is now the strongest model available on Claude Pro and the new default on Claude Max. If you use Claude Code on Max or API plans for heavy Bucktee plugin refactors or complex TypeScript work, you just got a free capability upgrade at no extra cost.

### [Claude Code 2.1.219 — Opus 5 Default + Depth-3 Subagents](https://code.claude.com/docs/en/changelog)
The July 24 CLI release adds Claude Opus 5 as the default Opus model, raises subagent nesting depth from 1 to 3 (configurable via `CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH`), ships a new `sandbox.network.strictAllowlist` setting to hard-deny non-allowlisted hosts in sandboxed commands, and adds the `DirectoryAdded` hook that fires when a new working directory is registered mid-session. The July 22 release (2.1.218) moved `/code-review` to run as a background subagent, keeping the main conversation uncluttered.
**Why it matters:** Depth-3 subagents make orchestration scripts meaningfully more powerful for multi-repo workflows; the `DirectoryAdded` hook unlocks hooks that react to `/add-dir`, useful for automating per-repo setup in your development environment.

### [Claude Tag in Slack Goes Live — Old App Retired August 3](https://support.claude.com/en/articles/15594475-what-is-claude-tag)
The new Claude Tag app launched August 3 on Slack Team and Enterprise plans, permanently replacing the older per-user Claude in Slack integration. Claude Tag is a persistent, multiplayer agent (running on Opus 4.8) with channel-level memory, connected tools, and optional ambient check-in behavior — the whole team shares one Claude instance per channel rather than each person running a separate session.
**Why it matters:** If your team uses Slack for coordination on the Bucktee plugin or Cloudflare deployments, this is now the integration to configure. The old app is gone as of today; any organization that hadn't migrated was auto-switched.

### [Claude Sonnet 5 Intro Pricing Expires August 31](https://benchlm.ai/anthropic/api-pricing)
Sonnet 5's launch pricing of $2 input / $10 output per million tokens reverts to the standard $3/$15 on September 1. The 50% usage boost for Claude Code subscribers is also extended only through August 19.
**Why it matters:** If you are building API-based features for Bucktee or other projects priced against Sonnet 5, budget the rate increase now; the clock is running.

### [Codex CLI 0.146.0 — Agent Plugins + Named Sessions](https://github.com/openai/codex/releases/tag/rust-v0.146.0)
Released July 29, this stable release introduces Agent Plugins manifests with workspace plugin publishing (and new marketplaces for Bedrock and Claude Code), named sessions via `/new` or `/clear` with pinnable threads, thread forking with paginated history, and WebSocket-based remote Code Mode connections. The 0.147.0 alpha train is already in progress.
**Why it matters:** The Claude Code plugin marketplace integration means Codex can now discover and use Claude Code skills/plugins directly — the two tools are becoming more interoperable for developers running both.

## 🟡 Noteworthy

### [Cloudflare Workflows Adds Per-Step Billing Starting August 10](https://developers.cloudflare.com/changelog/post/2026-07-07-workflows-billing-updates/)
Cloudflare announced that step and storage billing for Workflows on paid plans activates no earlier than August 10, 2026. Previously, Workflows costs were flat; now each step execution and state storage counts toward billing. Wrangler also gained a `check startup` command (also released this week) that reports raw and compressed bundle sizes plus CPU activity breakdown at startup.
**Why it matters:** If any of your Cloudflare Workers projects use Workflows for orchestration, audit your step counts before August 10. The `wrangler check startup` command is immediately useful for spotting bundle bloat in Workers.

### [Cloudflare: New Durable Object Namespaces Must Use SQLite Backend](https://developers.cloudflare.com/kv/)
Cloudflare now requires all newly created Durable Object namespaces to use the SQLite storage backend, deprecating the legacy key-value backend for new namespaces.
**Why it matters:** If you are adding Durable Objects to any new Cloudflare Workers project, there is no choice now — plan your schema around SQLite from the start.

### [Gemini CLI v0.53.0 Stable — ReAct Loop Mitigation + Workspace Security](https://github.com/google-gemini/gemini-cli/releases)
The July 28 stable release addresses ReAct loop runaway behavior and tightens workspace-level security. The v0.54.0 preview (same day) enforces HTTPS for `GoogleCredentialsAuthProvider`. Nightly builds in early August (v0.55.0-nightly) classified capacity exhaustion as terminal to prevent infinite retry hangs.
**Why it matters:** The ReAct loop fix is the most practically important change — runaway agent loops were a real reliability problem in earlier versions if you use Gemini CLI in automation pipelines.

### [WordPress/WooCommerce: Critical RCE Chain Actively Exploited (CVSS 9.8)](https://www.wordfence.com/vulnerability-advisories/)
Wordfence disclosed CVE-2026-60137 (unauthenticated SQL injection) and CVE-2026-63030 (critical REST API batch-route confusion, CVSS 9.8), which can be chained to achieve remote code execution against WooCommerce sites. Wordfence reports blocking over 11 million exploit attempts since disclosure. Premium users received a firewall rule on July 17; free users get it August 16.
**Why it matters:** This is a WooCommerce core attack surface — if your Bucktee plugin installs on WooCommerce sites, your customers are exposed until they update. Consider adding an update notice or compatibility check for affected WooCommerce versions in your plugin if you haven't already.

## 🧠 Takeaways

- **Anthropic is compressing its model ladder.** Opus 5 matches Fable 5 on coding benchmarks at half the price and the same price as Opus 4.8. The effective "best model you'd actually pay for" keeps getting cheaper, which is good for API-based product features — but it also means pricing tiers will likely shift again within a quarter.

- **Claude Code's agentic depth is growing faster than tooling to govern it.** Depth-3 subagent nesting and the new `DirectoryAdded` hook make Claude Code significantly more powerful for complex workflows, but the `sandbox.network.strictAllowlist` addition is a reminder that this power needs explicit security boundaries — configure it deliberately, not after the fact.

- **Cloudflare Workflows is no longer free to run at scale.** The August 10 billing start is a silent breaking change for teams that built unbounded-step orchestration assuming flat pricing. Audit before the deadline.

- **The WooCommerce RCE chain (CVSS 9.8) is actively exploited with 11M+ blocked attempts.** If you maintain a plugin that runs on WooCommerce sites, proactively communicating about affected versions is now a support obligation, not optional.
