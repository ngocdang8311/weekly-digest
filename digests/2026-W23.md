## 🔴 Critical

### [Claude Opus 4.8: New Default Model, Dynamic Workflows, Security-Guidance Plugin](https://www.anthropic.com/news/claude-opus-4-8)

Opus 4.8 shipped May 28 as the new default model for Max, Team Premium, Enterprise pay-as-you-go, and Anthropic API accounts (Claude Code v2.1.150–v2.1.157). It defaults to high effort, with `/effort xhigh` for the hardest tasks, and is reported to be ~4× less likely than Opus 4.7 to let code flaws pass without flagging them. Fast mode now runs at $10/$50 per MTok at 2.5× speed — 3× cheaper than the previous Fast tier. Two features shipped alongside: **Dynamic Workflows**, which lets Claude author and execute a coordination script that orchestrates dozens to hundreds of parallel subagents; and the **security-guidance plugin**, which continuously reviews Claude's own edits for vulnerabilities as it works. Browser agent performance reached 84% on Online-Mind2Web, firmly in production territory.

**Why it matters:** Dynamic Workflows make multi-agent orchestration first-class — directly useful for building automated pipelines across your Cloudflare Workers and WooCommerce/Bucktee codebase. The security-guidance plugin auditing Claude's own code changes is the most practical safety feature yet for agentic editing sessions, especially for TypeScript REST endpoints where subtle auth mistakes are costly.

Named permission profiles reduce setup friction when working across codebases with different trust boundaries (e.g., your Bucktee plugin repo vs. a client site).

### [Cloudflare Flagship Goes Public Beta — Edge-Native Feature Flags on Workers KV](https://blog.cloudflare.com/flagship/)

Flagship entered public beta on May 26 as a feature flag service that evaluates flags directly inside a Workers isolate with no outbound HTTP round-trips. Flag configuration lives in Workers KV; Durable Objects handle write coordination. The evaluation engine runs at the edge and supports typed flag values, percentage rollouts, targeting rules, and audit history. It ships OpenFeature-compatible SDKs, so it plugs into the standard feature-flag interface rather than a proprietary API. Also this week: Wrangler now detects AI coding agents on startup and offers to install Cloudflare skill files from `cloudflare/skills`, and tunnel QR codes are now printed below the URL for quick mobile access.

**Why it matters:** Zero-latency flag evaluation inside Workers is a qualitatively different product than a hosted flag service with an SDK that phones home — it means you can gate behavior per-request at edge speed with no additional network hop. For any Cloudflare Workers API layer backing your stack, this is now the cleanest native option for progressive rollouts, replacing third-party flag services.

## 🟡 Noteworthy

### [WooCommerce SQL Injection (CVE-2026-4798) & Arbitrary File Read (CVE-2026-4782)](https://owlpower.eu/woo-services/woocommerce-cve-may-2026/)

Two high-severity CVEs in the May 2026 WooCommerce roundup are worth flagging. CVE-2026-4798 is a time-based SQL injection via the `product_order` parameter in unauthenticated requests; critically, it triggers even if WooCommerce has been deactivated, because the vulnerable hooks remain registered after deactivation. CVE-2026-4782 is a path-traversal arbitrary file read that exposes any file the web server can read, including `wp-config.php` with database credentials and authentication salts. The May 2026 WooCommerce CVE count is up 4% month-over-month, with auth/authz failures dominating the high-severity list.

**Why it matters:** The hook-persistence issue in CVE-2026-4798 is the sharpest part: sites that ever had WooCommerce installed may carry the attack surface even after deactivation. If Bucktee shares a codebase with WooCommerce or has been deployed on sites where WC was previously active, verify that `product_order` and similar parameters reach database queries only through prepared statements, regardless of WC's active state.

## 🧠 Takeaways

- **Opus 4.8's self-auditing behavior is the most practically important safety improvement of the year.** "4× less likely to let code flaws pass unremarked" is a reliability claim, not a capability claim — Anthropic is separately optimizing for honesty alongside benchmark scores. For unattended agentic sessions writing production code, this directly reduces the review burden.
- **Cloudflare Flagship reframes feature flags as an edge primitive, not an infrastructure service.** Evaluation inside a Workers isolate with no external call means flag resolution adds zero observable latency. That's a different product category than any hosted flag service — worth evaluating as soon as it exits beta if you run any A/B logic in Workers.
- **WooCommerce's hook persistence after deactivation is the real systemic issue, not just the individual CVEs.** The CVE-2026-4798 attack pattern assumes WooCommerce was *ever* present — sites that migrated away remain exposed. Plugin developers should audit that their own hooks are fully cleaned up on `deactivate_` and `uninstall_` callbacks, not just assuming deactivation is a clean slate.
- **The AI coding tool market has hit pricing parity.** Seven serious tools now cluster at ~$20/mo standard and ~$200/mo power tier. The differentiation race is shifting to agent runtime architecture — specifically, how well each tool handles multi-turn, multi-file, and multi-agent tasks without supervision. Claude Code's Dynamic Workflows and Managed Agents are currently the only production-grade hosted multi-agent runtime in that set.
