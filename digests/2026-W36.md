# Weekly AI & Tooling Digest — 2026-W36

*Week of 2026-08-25 to 2026-08-31*

## 🔴 Critical

### [Claude Code v2.1.245–v2.1.251: Hook Events, Security Fixes, Cost-Optimization](https://github.com/anthropics/claude-code/releases)

Five releases shipped Aug 25–28 with two security patches and several new features:
- **v2.1.251**: `PreModelSwitch`/`PostModelSwitch` hook events for intercepting model switches; live streaming of foreground subagent tool calls to Remote Control clients. **Critical:** fixed a symlink path-traversal vulnerability in the file tool and a plugin path-traversal bug.
- **v2.1.248**: `--restricted` mode strips all built-in command/code tools (useful for locked-down CI); `experimental.cacheTtl` per agent frontmatter sets prompt cache TTL to `"5m"` or `"1h"`.
- **v2.1.247**: `/claude-api cost-optimize` profiles a project's API spend and walks through caching, batching, and model-selection levers.
- **v2.1.246**: Auto mode tab in `/permissions`; Bash tool latency reduced via snapshot function optimization.
- **v2.1.245**: Fixed startup crash on Linux glibc 2.44 (Arch, Fedora Rawhide, CachyOS).

**Why it matters:** The symlink/path-traversal security fixes in v2.1.251 are critical—update immediately. New hook events and `--restricted` mode give you tighter control over Claude Code in CI, and `experimental.cacheTtl` directly applies to cost-tuning agentic loops in the Claude Agent SDK.

### [Anthropic Agent SDK: per-agent Cache TTL, Restricted Mode, Admin API GA](https://releasebot.io/updates/anthropic/claude-developer-platform)

SDK v0.121.0 ships `experimental.cacheTtl` in agent frontmatter, cross-session messaging, and restricted mode alongside this week's Claude Code releases. The Admin API user-management endpoints (members, invites, groups, custom roles) for Claude Enterprise orgs are now generally available.

**Why it matters:** Per-agent cache TTL lets you tune prompt-cache strategy at the agent level—important for multi-agent workflows where different agents have very different context-reuse patterns, directly affecting cost at scale.

### [Cloudflare Workers: Node.js Compat Default, Access per-Worker, OAuth Scopes](https://developers.cloudflare.com/changelog/product/workers/)

Three platform changes this month:
- **Node.js compat default** (compat date ≥ 2026-08-04): `node:crypto`, `node:fs`, `node:stream`, `node:net`, `node:dns`, and more work without any flags. npm packages depending on these APIs now just work.
- **Access per-Worker** (Aug 14): Attach a Cloudflare Access policy to a Worker directly, protecting all routes and preview URLs automatically as domains change.
- **OAuth optional scopes for Wrangler/API MCP** (Aug 22): Choose which optional scopes to grant instead of approving every scope requested by a client.

**Why it matters:** The Node.js compat default removes the biggest friction point for porting TypeScript backend code to Workers—if any of your Cloudflare projects were blocked on `node:*` APIs, you can now drop the compat flag from `wrangler.toml`.

### [Codex CLI v0.149.0: Interactive Agents Dashboard + Shell Navigation](https://releases.sh/openai/codex)

Released Aug 20, v0.149.0 adds an interactive dashboard for searching, starting, renaming, and stopping agents; `/cd`, `/pwd`, `/cwd` commands for working-directory management in TUI sessions; `codex queue` for messaging existing local or remote sessions; expanded Vim editing motions (`cw`, `c$`, `cc`); and enhanced diagnostics for network/proxy failures.

**Why it matters:** The multi-session dashboard closes the operational gap with Claude Code's remote-control feature; if your team evaluates both CLIs, the workflow comparison is now closer than it's been.

## 🟡 Noteworthy

### [WooCommerce Subscriptions: PHP Object Injection → Unauthenticated RCE (CVE-2026-18391)](https://freshysites.com/security-bulletins/woocommerce-subscriptions-plugin-vulnerability-cve-2026-18391/)

PHP Object Injection vulnerability in WooCommerce Subscriptions (< v9.1.0) when High-Performance Order Storage (HPOS) is enabled. An unauthenticated attacker can escalate it to remote code execution via a gadget chain in bundled dependencies. Published Aug 12, 2026.

**Why it matters:** HPOS is on by default in recent WooCommerce installs, so this affects most Subscriptions deployments. If Bucktee runs on a site with WooCommerce Subscriptions, update to v9.1.0 now—this is exploitable without authentication.

## 🧠 Takeaways

- **Patch before anything else this week:** Claude Code v2.1.251 fixes two path-traversal vulnerabilities and WooCommerce Subscriptions has an unauthenticated RCE—both need immediate updates before new feature work.
- **Claude Code's hooks surface is becoming a real CI primitive:** `PreModelSwitch`/`PostModelSwitch`, `--restricted` mode, and `experimental.cacheTtl` together signal that Anthropic is positioning Claude Code as a composable pipeline tool, not just an interactive editor. Investing in hooks now has a compounding payoff.
- **Cloudflare's Node.js compat default is the quiet win of the week:** It silently unblocks a large class of Worker migrations; re-audit any Workers project that was previously limited by missing Node built-ins.
- **Gemini CLI is in limbo:** The mid-rebranding state makes it a poor choice as a primary CLI right now. Codex CLI's new agent dashboard is a more stable secondary option if you need something alongside Claude Code.
