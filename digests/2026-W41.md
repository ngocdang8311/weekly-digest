# Weekly AI & Tooling Digest — 2026-W41

*Week of 2026-09-28 to 2026-10-05*

## 🔴 Critical

### [Claude Code Mods (Plugins) Launch](https://code.claude.com/docs/en/changelog)
Anthropic shipped first-class mod support for Claude Code on October 1: TypeScript-based plugins that add custom UI panes, new slash commands, replacement behaviors, and MCP extensions — hot-reloading in the running session. Mods are shareable through a plugin directory.
**Why it matters:** This is a platform shift for Claude Code. You can now ship your own Bucktee-specific tooling or Cloudflare Workers deploy flows as a plugin, enforce team conventions without forking, and distribute them to others — without waiting on Anthropic to add features.

### [Claude Sonnet 5.5 Released](https://www.anthropic.com/news)
Launched September 28 as the faster, lower-cost sibling to Opus 5.5. Intended for high-throughput tasks where Opus 5.5 is over-powered.
**Why it matters:** If you're calling Claude via API in workflows or Claude Code sub-tasks, Sonnet 5.5 is the new default target — better price/performance than Sonnet 4.6 and with 5.5-family capability.

### [Claude Opus 5.5 + Model Report](https://www.anthropic.com/news)
Launched September 22, Opus 5.5 matches Fable 5.1 performance on most benchmarks at 40% lower cost than Opus 5. Anthropic published a Model Report on October 2 detailing safety evaluations.
**Why it matters:** Upgrading from Opus 5 to 5.5 in any existing Claude Code pipelines or API integrations is a straightforward cost cut with no capability regression.

### [Claude Code 2.1.288 — Reliability & UX Overhaul](https://releasebot.io/updates/anthropic/claude-code)
Smarter resume and recovery flows, stronger plugin and MCP error handling, improved permission and auto-mode behavior, fixes for cloud/SDK/screen-reader sessions.
**Why it matters:** The MCP handling and auto-mode fixes directly improve remote (cloud) Claude Code sessions — more reliable for scheduled tasks and CI pipelines.

### [Codex CLI v0.160.0](https://developers.openai.com/codex/changelog)
Released October 1. Adds agent command center history browsing (keyboard-accessible "Show more"), projectless sessions using workspace defaults when policy permits, and opt-in Guardian review for retrieving earlier user instructions. Fixes duplicate message sends on reconnect and Windows sandbox issues.
**Why it matters:** If you use Codex CLI alongside Claude Code, the projectless sessions feature lets you run quick one-off tasks without a project context — useful for scripting and prototyping.

### [Cloudflare Workers KV Instant (GA) + Legacy API Deadline Oct 15](https://blog.cloudflare.com/workers-kv-instant/)
Workers KV Instant (powered by Quicksilver) is now generally available: reads under 2ms at p99, 60% cheaper reads than classic KV mode. **Separate action item:** legacy KV namespace API routes under `/accounts/{account_id}/workers/namespaces/*` are deprecated as of July 15 and stop working October 15 — migrate to `/accounts/{account_id}/storage/kv/namespaces/*` before then.
**Why it matters:** Two things at once: KV Instant is a performance/cost win worth evaluating for any KV-heavy Worker. The Oct 15 deadline is a hard breaking change — if Bucktee or any of your Workers scripts use the old API routes directly, you have 10 days to migrate.

## 🟡 Noteworthy

### [CVE-2026-27540: WooCommerce Wholesale Lead Capture — CVSS 9.8, Active Exploitation](https://www.esecurityplanet.com/threats/news-woocommerce-plugin-flaw-php-web-shells/)
An unauthenticated arbitrary file-upload flaw in WooCommerce Wholesale Lead Capture ≤ 2.0.3.1 allows attackers to add `php` to allowed file types and upload PHP webshells. Patched in February (v2.0.3.2), but Wordfence has blocked 100,000+ exploitation attempts since June — still active in early October.
**Why it matters:** If any of your WooCommerce installs have this plugin, treat it as compromised until you verify the patched version is running and no webshells were dropped. Even adjacent B2B/wholesale WC plugin stacks are worth auditing.

### [Gemini CLI Nightly Stabilization (Oct 1–2)](https://github.com/google-gemini/gemini-cli/releases/tag/v0.64.0-nightly.20261001.gc6bccb7ec)
v0.64.0-nightly builds fix CPU hangs, append-only delta patching, state persistence, cancellation handling, and Windows compatibility. Note: Gemini CLI was replaced by Antigravity CLI for free-tier users in June; these releases are for paid/enterprise users only.
**Why it matters:** Only relevant if you're still evaluating Gemini CLI as a secondary coding tool. The free-tier sunset and continued nightly-only cadence suggest it's not gaining ground as a daily driver.

## 🧠 Takeaways

- **The Claude 5.5 family is now complete** (Opus + Sonnet landed within a week of each other). The practical move is to default new API integrations to Sonnet 5.5 and reserve Opus 5.5 for complex agentic work — don't leave pipelines on Opus 5 paying a 40% premium for the same output.
- **Claude Code mods change the game for team workflows.** The ability to ship TypeScript plugins that hot-reload in Claude Code sessions — and distribute them via directory — makes per-project or per-company tooling first-class. Expect this to widen the gap between Claude Code and editor-native tools like Cursor/Copilot that don't offer this extensibility model.
- **The Cloudflare KV API deprecation on Oct 15 is not optional.** It's easy to miss in changelog noise, but Workers or automation scripts still hitting the old `/workers/namespaces/` routes will hard-fail in 10 days. KV Instant's sub-2ms reads are also worth benchmarking for any latency-sensitive KV reads.
- **WooCommerce plugin hygiene remains a persistent risk.** CVE-2026-27540 is 8 months post-patch with 100K+ live exploit attempts — the attack surface isn't "have you patched the plugin" but "have you ever had it installed." A one-time file-integrity check across WC plugin directories is cheap insurance.
