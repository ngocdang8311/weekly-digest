# Weekly AI & Tooling Digest — 2026-W25

*Week of 2026-06-08 to 2026-06-14*

## 🔴 Critical

### [Claude Fable 5 Now Available in Claude Code — Run `claude update`](https://github.com/anthropics/claude-code/releases/tag/v2.1.170)
Anthropic introduced Claude Fable 5, a new Mythos-class model, available in Claude Code starting with v2.1.170 (released June 9). Three follow-up patch releases over the next three days (v2.1.173, v2.1.174) fixed model name normalization (stripping erroneous `[1m]` suffix) and enterprise banner visibility for the new model tier.
**Why it matters:** Claude Code is your primary tool — run `claude update` to unlock the new model without changing any workflow; Fable 5 is selectable directly from `/model`.

### [Claude Code v2.1.172: Sub-Agents Now Nest Up to 5 Levels Deep](https://github.com/anthropics/claude-code/releases/tag/v2.1.172)
Released June 10, v2.1.172 lifted the sub-agent depth cap from the previous limit to 5 levels. The same release added a search bar to the marketplace `/plugin` picker, fixed 1M-context sessions stalling without credits, improved long-conversation performance, and cut idle CPU usage.
**Why it matters:** Deep agent nesting unlocks real orchestration patterns — e.g., a planner agent spawning specialized sub-agents for TypeScript build, WP plugin deploy, and Cloudflare Worker publish in a single Claude Code session.

### [Claude Code v2.1.169: `--safe-mode`, `/cd` Command, `disableBundledSkills`](https://github.com/anthropics/claude-code/releases/tag/v2.1.169)
v2.1.169 (June 8) added `--safe-mode` to launch Claude Code with all hooks, MCP servers, and customizations disabled for debugging. A new `/cd` command moves the active session to a new directory without restarting. The `disableBundledSkills` setting (also available as an env var) suppresses all built-in skills for a fully custom configuration.
**Why it matters:** `--safe-mode` is an essential escape hatch when MCP server conflicts or hooks cause unexpected behavior; `disableBundledSkills` is the right primitive if you want to ship your own skill set for Bucktee development.

### [Claude Code v2.1.176: Bedrock Credential Caching Fix + `enforceAvailableModels`](https://github.com/anthropics/claude-code/releases/tag/v2.1.176)
Released June 12, this version fixes Bedrock credentials being dropped every hour regardless of actual expiration (now caches until the `Expiration` field). It also adds `enforceAvailableModels` as a managed setting to lock which models users can select, and session titles are now generated in the conversation language (configurable via `language` setting).
**Why it matters:** If you use Claude via AWS Bedrock, the credential caching fix alone prevents silent authentication failures mid-session.

### [Gemini CLI Sunsets for Free/Pro/Ultra Tiers on June 18 — Migrate to Antigravity CLI](https://github.com/google-gemini/gemini-cli/discussions/27274)
Google's Gemini CLI stops serving requests for free, Google AI Pro, and Google AI Ultra users on June 18, 2026. The replacement, Antigravity CLI (written in Go), retains Agent Skills, Hooks, and Subagents but renames extensions to "plugins" and carries reports of higher token consumption. Enterprise/Cloud API users are unaffected.
**Why it matters:** If you've used Gemini CLI as a secondary or comparison tool, you have until June 18 to migrate or drop it — the free path is gone. Claude Code's standalone position strengthens as Google fragments its CLI story.

## 🟡 Noteworthy

### [Cloudflare: Dynamic Workers Invocation Count in Dashboard + GraphQL API](https://community.cloudflare.com/t/workers-track-dynamic-workers-usage-from-the-dashboard-and-graphql-api/933293)
As of June 11, the Workers overview page in the Cloudflare dashboard shows the number of Dynamic Workers billed in the current billing period. The same metric is queryable via GraphQL (`workersInvocationsByOwnerAndScriptGroups`, field `distinctDynamicWorkerCount`). Data availability begins June 1, 2026.
**Why it matters:** Dispatch namespaces and dynamic routing are common patterns in multi-tenant Workers setups; previously you had to script GraphQL to track billing exposure — it's now a first-class dashboard metric.

### [WooCommerce CVE-2026-3589: CSRF Allows Unauthenticated Admin Account Creation](https://www.sentinelone.com/vulnerability-database/cve-2026-3589/)
A CSRF vulnerability in WooCommerce versions 5.4.0–10.5.2 lets an unauthenticated attacker exploit a logged-in administrator's browser session to call non-store WC REST endpoints and create arbitrary administrator accounts. Patched in versions after 10.5.2.
**Why it matters:** This is a store-takeover class vulnerability — any WooCommerce site (including Bucktee's host stores) still on ≤10.5.2 should treat this as urgent. Update WooCommerce and review admin user lists.

### [Windsurf Rebrands to Devin Desktop, Ships Open Agent Client Protocol](https://devin.ai/blog/windsurf-is-now-devin-desktop/)
Cognition completed the Windsurf rebrand on June 2, launching Devin Desktop with Devin Local (Rust rewrite of the Cascade agent), Agent Command Center as the primary UI surface, and built-in support for the open Agent Client Protocol (ACP). Under ACP, Claude Agent, Codex, and Gemini CLI run as first-class agents inside a single IDE without vendor lock-in.
**Why it matters:** ACP is the first credible attempt at a vendor-neutral multi-agent IDE protocol — if it gains traction, Claude Code workflows could be orchestrated from within Devin Desktop alongside other agents. Worth watching but not adopting yet.

## 🧠 Takeaways

- **Run `claude update` right now.** This week saw six Claude Code releases, with Fable 5 availability and 5-level sub-agent nesting being the two standout capability changes — neither requires config changes, just the update.
- **Gemini CLI's free tier death on June 18 is the most underreported story this week.** Google is consolidating behind a paid API path; Anthropic is keeping Claude Code free-tier-friendly. The moat around Claude Code's daily-driver position is widening.
- **CVE-2026-3589 is high-severity and WooCommerce-specific** — unauthenticated CSRF to admin account creation is a full store compromise vector. If you maintain Bucktee installs on client sites, verify all are past 10.5.2 before end of week.
- **Devin Desktop's open ACP protocol is strategically interesting but the rebrand has community friction.** Cognition inherited Windsurf's user base but not its goodwill; actual agent quality under the new brand is unproven. Track the protocol, not the product.
