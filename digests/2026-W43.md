## 🔴 Critical

### [Claude Haiku 5.5 released — now the default Haiku model](https://code.claude.com/docs/en/changelog)
Anthropic shipped Claude Haiku 5.5 on October 7 (`claude-haiku-5-5`), replacing Haiku 4.5 as the default. It costs $0.10/$0.50 per million tokens (input/output) with a 1M-token context window; prompts over 100K tokens incur a 5× surcharge ($0.50/$2.50). Adaptive thinking and adjustable effort are included.

**Why it matters:** Haiku 5.5 is the sensible default for high-volume Claude Code subagents, Cloudflare Worker edge calls, and lightweight Bucktee plugin tasks where Sonnet 5.5 would be overkill. Recalculate cost budgets accordingly.

### [Claude Code v2.1.293–v2.1.303: 10 releases in 12 days](https://code.claude.com/docs/en/changelog)
The past week brought a torrent of Claude Code updates. The most operationally significant:

- **v2.1.302 (Oct 16):** `CLAUDE_CODE_AUTO_MODE_MODEL` lets you pin the auto-mode classifier model. Fork subagents are now **on by default** outside the terminal; disable with `CLAUDE_CODE_FORK_SUBAGENT=0`. Claude Design service closing December 14, 2026.
- **v2.1.301 (Oct 15):** LaTeX math rendering in VS Code, Vim `%` motion, OpenTelemetry classifier fields in `tool_decision` events.
- **v2.1.300 (Oct 14):** New `prompt.change` mod hook, cache-write token breakdown in OpenTelemetry traces, `/advisor` support on Claude Platform on AWS.
- **v2.1.299 (Oct 14):** Idle compaction kicks in after ~54 min idle on 200K+ token conversations (`CLAUDE_CODE_IDLE_COMPACT_MIN_TOKENS` to tune). MCP protocol version 2026-07-28 is now the default for cloud connectors.
- **v2.1.296 (Oct 9):** `CLAUDE_CODE_WORKFLOW_SUBAGENT_MODEL` to pin a single model for all workflow subagents. MCP tool description limit raised from 2,048 → 4,096 characters. Sonnet 5.5 cache reads confirmed at **$0.10/M tokens**.

**Why it matters:** The fork-subagents-on-by-default change affects any Claude Code workflow or cloud session — check that existing pipelines aren't inadvertently doubling agent costs. The `CLAUDE_CODE_WORKFLOW_SUBAGENT_MODEL` env var is a practical cost lever for your multi-step workflows.

### [Cloudflare legacy Workers KV API deadline: October 15 (passed)](https://developers.cloudflare.com/changelog/post/2026-07-15-kv-legacy-namespace-routes-deprecation/)
The old REST management API routes under `/accounts/{account_id}/workers/namespaces/*` stopped working on October 15, 2026. The replacement path is `/storage/kv/namespaces`. **Worker scripts using the binding API are unaffected** — this only hits scripts, Terraform, and CI/CD pipelines that call the management REST API directly.

**Why it matters:** If your Bucktee CI/CD pipeline or any Cloudflare tooling scripts provision or manage KV namespaces via REST, they broke on Oct 15. Migrate to the new path immediately.

---

### [Workers KV namespace jurisdictions now GA](https://developers.cloudflare.com/changelog/post/2026-10-02-kv-jurisdictions-ga/)
KV namespace jurisdictions (`eu`, `us`, `fedramp`) reached general availability on October 2. Jurisdiction is **set at namespace creation and cannot be changed afterwards**.

**Why it matters:** If you're storing EU-resident user data in KV (e.g., Bucktee customer order data from EU WooCommerce stores), you can now pin data residency to `eu` at namespace creation. Do it before the namespace fills — you won't be able to migrate an existing namespace.

## 🟡 Noteworthy

### [Codex CLI v0.163.0: mid-response steering now default](https://tech-insider.org/codex-cli-0-163-ai-coding-agents-2026/)
Released October 15. Mid-response steering — the ability to redirect the agent while it is still generating — is now enabled by default rather than opt-in. Also: `GPT-5.5` was retired from Codex for ChatGPT-authenticated sessions on October 14 (API-key sessions unaffected). GPT-6.1 Sol became the default model as of v0.161 (October 7).

**Why it matters:** If you run Codex CLI alongside Claude Code for comparison/fallback, the model default shift to GPT-6.1 Sol may change cost and output characteristics in your scripts.

Released October 13. Focused on reliability: fixes for file operations, state recovery, cancellation, and Windows terminal behavior. ### [WooCommerce core privilege escalation CVE-2026-106608 (CVSS 7.2)](https://www.thehackerwire.com/vulnerability/CVE-2026-106608/)
An incorrect privilege assignment flaw was published October 10, affecting WooCommerce **9.8.0 through 11.1.2**. No patch confirmation found in these sources — check woocommerce.com/changelog and Wordfence immediately if you're in this version range.

**Why it matters:** Directly affects WooCommerce. If Bucktee runs on a store with WooCommerce 9.8–11.1.2, verify whether a patched version is out and prioritize updating.

### [EU VAT Assistant for WooCommerce: stored XSS via guest checkout (CVE-2026-103899, CVSS 7.2)](https://www.strix.ai/cve/CVE-2026-103899)
Stored XSS in versions ≤ 2.1.30 executes in an admin's browser when they review an order via WooCommerce → Orders → Edit Order. Reachable without authentication.

**Why it matters:** A common plugin on VAT-compliant EU WooCommerce stores. If Bucktee's target stores use this plugin, flag it to customers.

## 🧠 Takeaways

- **Claude Code's release cadence is a product strategy.** Ten releases in twelve days isn't maintenance — it's Anthropic widening the gap between Claude Code and every fork-style competitor (Cursor, Windsurf/Devin Desktop) that ships on a weekly or monthly cycle. The fork-subagents-on-by-default change and the new `CLAUDE_CODE_WORKFLOW_SUBAGENT_MODEL` env var both point toward workflows and automation as the primary growth vector.

- **Haiku 5.5 resets the cost math for agentic tasks.** At $0.10/$0.50/M tokens with 1M context, Haiku 5.5 is a credible default for every low-stakes subagent call. Stop defaulting all agents to Sonnet unless the task genuinely needs it.

- **The Cloudflare KV API migration was a silent breaking change.** No deprecation warning banner in the developer portal, no in-dashboard alert — just a deadline that passed. Check all infra automation scripts now. The jurisdictions GA is useful, but the deadline is urgent.

- **WooCommerce keeps accumulating high-severity CVEs in adjacent plugins.** Two CVSS 7.2 issues in one week — one in core, one in a popular EU compliance plugin — signals that the WooCommerce plugin ecosystem's security posture is still weak. A regular Wordfence/Patchstack scan on Bucktee's target environments is overdue.
