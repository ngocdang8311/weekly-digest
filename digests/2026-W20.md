# Weekly AI & Tooling Digest — 2026-W20

*Week of 2026-05-04 to 2026-05-10*

## 🔴 Critical

### [Anthropic Doubles Rate Limits After SpaceX Compute Deal](https://www.anthropic.com/news/higher-limits-spacex)

Announced May 7. Anthropic signed a deal with SpaceX to access all compute capacity at the Colossus 1 data center — 300 MW, ~220,000 NVIDIA GPUs — with capacity coming online within the month. On the user-facing side: five-hour rate limits doubled for Pro, Max, Team, and seat-based Enterprise plans; peak-hour reductions removed entirely for Pro and Max; Opus API rate limits raised significantly.

**Why it matters:** If you've been hitting Claude Code's five-hour wall mid-agentic-session (Bucktee refactors, long Workers migration runs), those limits are now effectively gone for most realistic workloads. The removal of peak-hour throttling is the more meaningful change — consistent throughput across the day is worth more than raw limit numbers.

### [Claude Code v2.1.128 → v2.1.138: MCP Reliability, Session ID Env Var, CLAUDE_EFFORT in Hooks](https://github.com/anthropics/claude-code/releases)

Eight releases across May 4–9. The most substantive changes landed in v2.1.136 (May 8): fixed MCP servers losing their configured state after `/clear`; fixed MCP OAuth refresh tokens being dropped under concurrent refreshes. v2.1.132 (May 6) added `CLAUDE_CODE_SESSION_ID` to the Bash tool subprocess environment (same value passed to hooks) and `CLAUDE_EFFORT` accessible in hooks and Bash tools. v2.1.129 added plugin URL support and history-picker improvements. Multiple Windows VS Code activation fixes in v2.1.131 and v2.1.137.

**Why it matters:** The MCP state-after-clear bug was a real friction point — if you use MCP servers with OAuth (e.g., GitHub, Notion) and `/clear` between tasks, tokens were being silently dropped. `CLAUDE_CODE_SESSION_ID` in Bash subprocess scope finally lets hook scripts correlate shell commands to sessions without workarounds.

### [Codex CLI v0.130.0: `codex remote-control`, Bedrock AWS Console Auth, Thread Pagination](https://github.com/openai/codex/releases)

Released May 8. Key additions: new `codex remote-control` command for headless app-server startup (replaces the previous startup flag pattern); Bedrock authentication now accepts AWS console-login credentials directly, removing the requirement for explicit API keys in Bedrock deployments; large threads can now be paginated with flexible view options; plugin details panels display bundled hooks inline; `view_image` resolves correctly across all selected environments. GPT-5.5 remains the recommended model for complex coding tasks when available in the picker.

**Why it matters:** The Bedrock auth improvement is the most practically significant — if you or any team members route Codex through AWS Bedrock for billing or compliance reasons, the setup friction just dropped substantially. Remote-control mode is also worth watching if you're building tooling that drives Codex programmatically.

### [Gemini CLI v0.41.0 Stable: Voice Mode GA, Gemma 4 Support, Shell Validation Hardening](https://github.com/google-gemini/gemini-cli/releases)

v0.41.0 released May 5 as a stable release (previously preview in W19). Ships real-time voice mode with cloud and local processing backends; Gemma 4 model support (experimental, opt-in); mandatory workspace trust enforcement for headless environments; core tools allowlist for shell command validation to block unauthorized execution. v0.41.2 patch (May 6) fixed a race condition in tool completion waiting.

**Why it matters:** Voice mode in a terminal CLI is a genuine first-mover feature — neither Claude Code nor Codex CLI has shipped audio input. The security hardening (workspace trust + shell allowlist) is directly relevant if you're evaluating any CLI agent for use in CI or shared environments. Gemma 4 support signals that Gemini CLI is becoming model-agnostic, not just a Gemini wrapper.

### [Cloudflare Workers AI: Three New Models, Kimi K2.5 Deprecation Extended to May 30](https://developers.cloudflare.com/changelog/post/2026-05-08-planned-model-deprecations/)

Model catalog refresh (May 8). Added: `@cf/zai-org/glm-4.7-flash` (fast multilingual, multi-turn tool calling), `@cf/google/gemma-4-26b-a4b-it` (vision + tool calling), `@cf/moonshotai/kimi-k2.6` (capable agentic/coding model with vision). Kimi K2.5 deprecation extended from May 10 → May 30; on May 30 requests auto-alias to K2.6 at a higher price point. Workers Media also shipped Stream bindings this week — upload videos, manage metadata, generate signed playback URLs directly from a Worker without authenticated API calls.

**Why it matters:** If you're using Workers AI for inference in any Bucktee plugin hooks or Cloudflare-hosted AI features, the auto-alias behavior on May 30 means a silent price change unless you pin to `kimi-k2.6` explicitly now. The Gemma 4 addition also gives you a free, capable open model with vision directly in the Workers runtime.

### [GitHub Copilot Usage-Based Billing Preview Dashboard Now Live](https://github.blog/news-insights/company-news/github-copilot-is-moving-to-usage-based-billing/)

The preview billing experience for Copilot's June 1 usage-based transition rolled out in early May. All users and org admins can now see projected AI Credit consumption before the cutover. Heavy consumers: Copilot Chat, agentic sessions, code review — each consume credits based on token count. Copilot code completions and Next Edit suggestions remain outside the credit system. Monthly Copilot plan users auto-migrate June 1; annual-plan users stay on current pricing until renewal.

**Why it matters:** Pull your preview bill now if you have any team members using Copilot for agentic workflows. A single complex multi-file session can look very different under token billing vs. the old flat rate. The surprise will hit invoices, not dashboards, if you don't check before June 1.

## 🧠 Takeaways

- **Anthropic's compute bet is landing in user hands immediately.** The SpaceX deal going from announcement to doubled limits within days is unusually fast. This is the most direct benefit to daily Claude Code users in months — more relevant than any feature release this week.
- **Gemini CLI is the only major CLI with stable voice input.** Google shipped voice mode to stable while Codex and Claude Code are both purely text-based. This isn't a gimmick in headless environments, but it is meaningful for ambient or accessibility use cases. If Google keeps this pace it will have genuine differentiation on input modalities.
- **Cloudflare's silent price change on May 30 is easy to miss.** The auto-alias from Kimi K2.5 → K2.6 looks like a deprecation extension but is actually a forced model upgrade with a higher price. If you have any Workers AI calls without an explicit model pin, audit them before May 30.
- **MCP reliability is still Claude Code's biggest surface area for improvement.** Four of the eight releases this week touched MCP — state loss on `/clear`, OAuth token races, retry logic. The surface is maturing but these were foundational bugs that should have been caught earlier. If you're building MCP-dependent workflows (Bucktee tooling, custom servers), pin to a tested version and test `/clear` behavior explicitly.
