## 🔴 Critical

### [Claude Code 2.1.271–2.1.278: AGENTS.md, Plugin Marketplace, Server-Side Classifier](https://code.claude.com/docs/en/changelog)
Seven releases shipped across the week. Highlights: `AGENTS.md` is now a supported alternative to `CLAUDE.md` for project instructions; auto mode for API/Enterprise users now defaults to the server-side classifier (no classifier-overhead charges); `/plugin install <plugin> --marketplace <source>` enables remote plugin installation; skills and plugins now sync from claude.ai to terminal sessions; session forking is available from Remote Control; and `allowed_domains` per-command landed for Bash/PowerShell in auto mode. A critical 400-error regression when routing through a proxy/gateway (introduced in 2.1.275) was patched same-day in 2.1.276.
**Why it matters:** AGENTS.md and the plugin marketplace are direct workflow improvements for Claude Code daily use—you can now keep project instructions in a file that other AI tools (e.g., Codex, Gemini) also recognize, and install plugins non-interactively in CI or containerized Claude apps setups. The gateway 400-fix is essential if you run Claude Code behind a corporate proxy.

### [Codex CLI v0.153.0: Plugin Marketplace, Vim Undo/Redo, Token Budgets](https://releasebot.io/updates/openai/codex)
v0.153.0 introduced: a plugin CLI that can list/install/remove plugins from remote marketplaces (Curated, Workspace, Shared); vim mode undo (`u`) and redo (`Ctrl+R`) with full draft preservation including attachments; configurable rollout token budgets that track usage across agent threads and abort turns when exhausted; and an indexed web-search mode with server-approved URL allowlisting. `GPT-5.3-Codex-Spark` was deprecated on September 14.
**Why it matters:** Token budget enforcement is a meaningful guardrail for autonomous Codex agents running unattended—relevant if you are evaluating Codex vs. Claude Code for long-running tasks.

### [Gemini CLI Rebrands to Antigravity CLI — Migration Required](https://releasebot.io/updates/google/gemini-cli)
Google unified its developer tools into a single multi-agent platform called **Antigravity**. As of June 18, Gemini CLI stopped serving requests for individual/Pro/Ultra tiers; users must migrate to `antigravity` CLI. Additionally, a Server-Side Request Forgery (SSRF) vulnerability was patched in Agent Studio web apps created before July 1, 2026. The CLI now includes process-level sandboxing and automatic update checks.
**Why it matters:** If you have any scripting or CI pipelines invoking `gemini` CLI, they are currently broken or will break soon—rename commands and update PATH. The SSRF fix is worth noting if you ever scaffolded a web app with Agent Studio.

### [Cloudflare Workers KV: Legacy API Sunset October 15 + Latency Rollout Complete](https://developers.cloudflare.com/changelog/product/kv/)
Two concurrent KV updates: (1) The legacy API routes under `/accounts/{id}/workers/namespaces/*` are deprecated since July 15 and **will stop working October 15, 2026**—migrate to `/accounts/{id}/storage/kv/namespaces/*`. (2) KV's rolling latency improvement is now fully deployed across all namespaces, delivering measurable read-latency reductions globally. Separately, Workflows instances created after September 10 on the Paid plan retain completed/errored state for 7 days (down from 30 days).
**Why it matters:** The KV API sunset is a hard deadline 24 days out. Any Cloudflare Workers code (including Bucktee plugin backend or KV-backed caching) using the old namespace routes will break on Oct 15—audit now and migrate. The Workflows state retention cut also matters if you rely on Cloudflare Workflows for order processing or async jobs.

## 🟡 Noteworthy

### [CVE-2026-27540 (CVSS 9.8): WooCommerce Wholesale Lead Capture Actively Exploited](https://www.scworld.com/brief/hackers-exploit-critical-woocommerce-plugin-vulnerability)
An unauthenticated arbitrary file upload flaw in `WooCommerce Wholesale Lead Capture` (all versions ≤ 2.0.3.1) is under active mass exploitation—Wordfence blocked over 100,000 attacks. Attackers upload PHP web shells, enabling full remote code execution. The patch landed in v2.0.3.2 back in February; exploitation has been ongoing since June but is peaking now. A second, lower-severity reflected XSS was disclosed September 18 in the ShopLentor plugin (CVE-2026-92554).
**Why it matters:** If Bucktee's WooCommerce environment or any client sites use Wholesale Lead Capture, update immediately to ≥ 2.0.3.2. Also check access logs for `wwlc_file_upload_handler` AJAX calls—if that endpoint was ever hit, assume compromise and investigate.

## 🧠 Takeaways

- **The AGENTS.md standard is converging.** Claude Code, Codex CLI, and other tools are coalescing around `AGENTS.md` as a cross-tool project instruction file—worth migrating your CLAUDE.md setups to `AGENTS.md` now so your repos work natively across tools.

- **Cloudflare KV API migration is genuinely urgent.** October 15 is 24 days away; the legacy routes go dark with no grace period indicated. This is the most time-sensitive operational action from this week.

- **Gemini CLI is effectively dead under that name.** Google's Antigravity rebrand was soft-launched months ago but is now the hard requirement. If you were watching Gemini CLI as a Claude Code alternative, re-evaluate against Antigravity CLI's new surface area.

- **The WooCommerce exploit wave is not slowing down.** 100k+ attacks on a plugin with ~6,000 installs means essentially every vulnerable site has been probed. Patch-time-lag continues to be the actual risk in the WordPress ecosystem—automated plugin update policies are no longer optional for production stores.
