## 🔴 Critical

### [Claude Code v2.1.163–2.1.168: fallbackModel, Deny-All Glob, Hooks additionalContext](https://github.com/anthropics/claude-code/releases)

Five releases landed June 4–6. The headliner is `fallbackModel` in settings: configure up to three fallback models tried in sequence when the primary is overloaded or returns a non-retryable error — Claude Code now auto-retries the failed turn on the next model rather than surfacing an error. Deny rules now accept `"*"` as a glob in the tool-name position, letting you deny all tools in one line. Cross-session security tightened: messages relayed via `SendMessage` from another Claude session no longer inherit user authority, which closes a privilege-escalation path in multi-agent setups. `Stop` and `SubagentStop` hooks can now return `hookSpecificOutput.additionalContext` to pass structured data back to the orchestrating session. `/plugin list` ships with `--enabled`/`--disabled` filters, and managed settings gain `requiredMinimumVersion`/`requiredMaximumVersion` guardrails for enterprise rollouts.

**Why it matters:** `fallbackModel` is a direct quality-of-life fix for Claude Code sessions that hit Opus 4.8 rate limits mid-task — you can now chain Opus 4.8 → Sonnet 4.6 → Haiku 4.5 without restarting the session. The `SendMessage` hardening matters if you're building multi-agent pipelines (e.g., orchestrators delegating to Bucktee-aware sub-agents) — cross-session privilege assumptions were a latent footgun.

### [Claude API: claude-sonnet-4-20250514 and claude-opus-4-20250514 Retire June 15](https://platform.claude.com/docs/en/about-claude/model-deprecations)

Anthropic confirmed the June 15, 2026 retirement date for both `claude-sonnet-4-20250514` and `claude-opus-4-20250514` (the original May 2025 Claude 4 checkpoints). After that date any API calls to these model IDs will fail. Successors are `claude-opus-4-7`, `claude-opus-4-8`, `claude-sonnet-4-6`, and `claude-haiku-4-5-20251001`.

**Why it matters:** One week out. If you have hardcoded model IDs anywhere in your Cloudflare Workers, Bucktee plugin backend calls, or any TypeScript/Next.js API routes hitting the Anthropic SDK, they break on Sunday. Audit `grep -r 'claude-.*-20250514'` across all repos now.

### [Gemini CLI Sunsets for Free/Pro/Ultra Users on June 18 — Replaced by Antigravity CLI](https://phemex.com/news/article/google-to-retire-gemini-cli-introduces-antigravity-cli-by-june-18-2026-83693)

Google announced Gemini CLI and Gemini Code Assist IDE extensions will stop serving requests for Google AI Pro, Ultra, and free-tier users on June 18, 2026. The replacement is **Antigravity CLI**, billed as an "agent-first" platform built for multi-agent coordination. Gemini CLI will continue working only for paid Gemini Enterprise Agent Platform API keys. Google acknowledged Antigravity CLI won't have 1:1 feature parity at launch. Last stable Gemini CLI release was v0.44.0 (May 27).

**Why it matters:** If Gemini CLI was in your rotation alongside Claude Code and Codex CLI, it effectively becomes enterprise-only in 10 days. Antigravity CLI is unproven at launch — budget time to evaluate or drop it from your workflow entirely until it stabilizes.

### [Cloudflare KV: Namespace Limit 200 → 1000, Bulk Read 100 Keys, Latency Improvements](https://developers.cloudflare.com/kv/)

Three meaningful KV updates shipped this week. Namespace limits quadrupled from 200 to 1000 per account with no pricing change. A new bulk-read API lets you fetch up to 100 keys in a single Worker invocation, cutting the round-trip overhead that previously forced multiple sequential reads. Cloudflare also completed a infrastructure rollout delivering "significant latency reduction on read operations across all KV namespaces." Separately, billable-usage widgets and budget alerts are now embedded in the sidebar of every product — Workers, KV, D1, R2, Queues, Durable Objects, Containers — letting you see current-period spend without navigating to the billing page.

**Why it matters:** The bulk-read API is the most practically useful change: any Cloudflare Worker that looks up per-user settings or cached WooCommerce product data can now collapse N sequential KV reads into one, reducing cold-path latency and CPU time billed. The namespace limit increase matters if you're partitioning KV by environment or customer across a multi-tenant setup.

## 🟡 Noteworthy

### [Windsurf Is Now Devin Desktop — Agent Client Protocol (ACP) Goes Mainstream](https://devin.ai/blog/windsurf-is-now-devin-desktop)

On June 2, Cognition rebranded Windsurf as **Devin Desktop** via an OTA update and made the Agent Command Center the default surface. The key technical shift: native support for the open **Agent Client Protocol (ACP)**, which means Codex, Claude Agent, OpenCode, and any ACP-compatible agent can run inside Devin Desktop from a single Kanban view. The bundled local agent (Devin Local) is a full Rust rewrite of Cascade, claiming 30% better token efficiency and subagent support. JetBrains, Google, and GitHub have all adopted ACP, and this rebrand is described as the largest single ACP adoption event to date.

**Why it matters:** Claude Agent's ACP support means your existing Claude Code sessions could eventually surface inside Devin Desktop without workflow changes — worth watching if you ever run multiple agents in parallel on a codebase. The open protocol is a genuine shift away from siloed editors toward a shared agent runtime.

### [GitHub Copilot Switches to Usage-Based AI Credits Billing on June 1 — New $100/mo Max Tier](https://www.codeant.ai/blogs/best-ai-code-editor-cursor-vs-windsurf-vs-copilot)

Copilot moved from request-based to token-metered AI Credits billing on June 1. Code completions remain free; everything agentic (Copilot Workspace, agent mode, multi-file edits) now meters by the token. A new $100/month Max tier targets heavy individual users who need sustained agentic throughput.

**Why it matters:** Copilot's cost model now resembles Claude Code's — the comparison is no longer "flat-rate vs. per-call" but "which tokens buy more value." If you're evaluating Copilot as a secondary tool, the variable cost makes it harder to budget alongside Claude Code's subscription.

### [WooCommerce Funnel Builder Plugin Under Active Exploitation — 40,000+ Stores at Risk](https://thehackernews.com/2026/05/funnel-builder-flaw-under-active.html)

A critical unpatched vulnerability in the Funnel Builder for WooCommerce plugin (40k+ installs) is under active exploitation, allowing unauthenticated attackers to inject arbitrary JavaScript into every checkout page. Skimmers are targeting payment card data at the point of capture. The patch is **version 3.15.0.3** — stores running any earlier version are live targets.

**Why it matters:** Checkout-page JS injection is the highest-severity WooCommerce attack class because it bypasses server-side protections entirely. If Bucktee or any client site uses Funnel Builder, update immediately. More broadly, audit checkout-adjacent plugins for unauthenticated write surfaces — this attack pattern is being replicated across similar funnel/page-builder plugins this month.

## 🧠 Takeaways

- **Claude Code is shipping like a startup, not a mature product.** Five releases in three days (v2.1.163–168), each with substantive features, signals Anthropic is in a rapid iteration cycle. The `fallbackModel` and cross-session security fixes address real agentic-workflow failure modes — keep auto-update on and read the changelog weekly, because capability assumptions can shift between sessions.

- **June 15 is a hard deadline — one week away.** The claude-*-20250514 deprecation is not a soft sunset with graceful fallback. Any hardcoded model string in production (Workers, Bucktee PHP backend, TypeScript API clients) becomes a runtime error next Sunday. This is the most urgent action item in this digest.

- **The AI tooling layer is consolidating around open protocols.** ACP adoption by JetBrains, Google, GitHub, and now Windsurf/Devin in the same month suggests the ecosystem is converging on agent interoperability rather than continuing to build walled gardens. Claude Agent's first-class ACP support means Anthropic's bet is to be the best agent, not just the best editor.

- **Gemini CLI's abrupt sunset is a cautionary tale about free-tier AI tooling.** Google crowdsourced 6,000 contributions from the community and then moved the product to enterprise-only within months. Treat any free-tier AI CLI as potentially transient infrastructure — weight tool investments toward tools with clear commercial models (Claude Code, Codex CLI) or truly open-source alternatives.
